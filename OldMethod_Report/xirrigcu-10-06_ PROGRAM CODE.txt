C     THIS PROGRAM COMPUTES MONTHLY CROP IRRIGATION CONSUMPTIVE USES USING THE
C     ORIGINAL BLANEY-CRIDDLE METHOD OR THE SCS MODIFIED BLANEY-CRIDDLE METHOD.
C     THE USER MAY SELECT EITHER METHOD, AND ALSO MAY SELECT USE OF A CROP
C     PRODUCTION FUNCTION FOR ALFALFA TO DETERMINE THE MINIMUM CONSUMPTIVE USE
C     BY THAT CROP, IF DESIRED. THE NEW MEXICO OFFICE OF THE STATE ENGINEER MAY
C     USE THE ALFALFA CROP PRODUCTION FUNCTION (SAMMIS, 1979, 1982) TO DETERMINE
C     THE MINIMUM CONSUMPTIVE USE BY ALFALFA BASED ON REPORTED CROP YIELDS IN
C     SOME AREAS OF THE STATE. THE USER ALSO INPUTS THE GROWTH SEASON START AND
C     END TEMPERATURES FOR EACH CROP, WHETHER THEY ARE THE SCS RECOMMENDED START
C     AND END TEMPERATURES OR OTHER TEMPERATURES, AND THE MAXIMUM LENGTH OF THE
C     GROWING SEASON TO MATURITY FOR ANNUAL CROPS. THE USER ALSO MAY SPECIFY
C     LIMITS TO THE GROWING SEASON TO REFLECT PLANTING AND HARVEST DATES OR
C     DATES OF IRRIGATION WATER DELIVERIES.
C
C     SHORTED IRRIGATION CONSUMPTIVE USES ARE DETERMINED BY THE USER EITHER BY
C     INPUTING A WATER SUPPLY CUTOFF DATE FOR A CROP, SUCH AS FOR SHORTED
C     ALFALFA OR PASTURE GRASS, OR BY INPUTING A PERCENTAGE SHORTAGE TO BE
C     APPLIED TO THE FULL SUPPLY CONSUMPTIVE USE FOR AN IRRIGATED AREA. SUPPLY
C     CUTOFF DATES SHOULD REFLECT A PERIOD OF TIME FOLLOWING THE LAST IRRIGATION
C     WATER APPLICATION FOR THE USE OF IRRIGATION WATER BY THE CROP.
C
C     INCIDENTAL IRRIGATION DEPLETIONS ARE DETERMINED BY APPLICATION OF USER-
C     DEFINED INCIDENTAL DEPLETION FACTORS FOR EACH IRRIGATED AREA. INCIDENTAL
C     DEPLETION FACTORS, OR INCIDENTAL DEPLETIONS EXPRESSED IN PERCENT OF CROP
C     CONSUMPTIVE USE, ARE INPUT FOR FLOOD, SPRINKLER AND DRIP IRRIGATION. THE
C     INCIDENTAL DEPLETION FACTORS SHOULD INCLUDE ALL DEPLETIONS INCIDENT TO THE
C     DIVERSION AND USE OF WATER FOR IRRIGATION, INCLUDING THOSE RESULTING FROM
C     CANAL LOSSES, ON-FARM LOSSES AND BELOW-FARM LOSSES. SOIL EVAPORATION
C     RESULTING FROM PRE-PLANT IRRIGATION ALSO SHOULD BE INCLUDED IN THE
C     INCIDENTAL DEPLETION FACTORS. THE USER DEFINES THE AMOUNT OF ACRES
C     IRRIGATED BY EACH IRRIGATION METHOD, AS WELL AS THE CROPPING PATTERN.
C
C     THE SUBROUTINE CIRCAL IN THIS PROGRAM ADAPTS FORTRAN CODE ORIGINALLY
C     DEVELOPED BY THE NEW MEXICO OFFICE OF THE STATE ENGINEER FOR COMPUTING
C     CROP CONSUMPTIVE IRRIGATION REQUIREMENTS USING EITHER THE ORIGINAL BLANEY-
C     CRIDDLE METHOD OR THE SCS MODIFIED BLANEY-CRIDDLE METHOD. THE ORIGINAL
C     STATE ENGINEER OFFICE FORTRAN CODE HAS BEEN MODIFIED TO ALLOW THE SAME
C     PRECISION TO BE USED IN THE APPLICATION OF THE CROP GROWTH STAGE CURVES
C     (Kc) IN THE MODIFIED BLANEY-CRIDDLE METHOD AS IS USED IN THE US BUREAU OF
C     RECLAMATION'S XCONS2 CROP CONSUMPTIVE USE CALCULATION PROGRAM, AND TO
C     ALLOW SELECTION OF BEGINNING AND END DATES FOR THE GROWING SEASONS BASED
C     ON EITHER TEMPERATURES, GROWING SEASON LENGTHS OR PLANTING/HARVEST/CUTOFF
C     DATES, WHICHEVER ARE LIMITING. ALSO, POSSIBLE EXTENSION OF THE GROWING
C     SEASONS TO INCLUDE ANY PERIODS OF PRE-PLANT IRRIGATION HAS BEEN REMOVED
C     FROM THE ORIGINAL STATE ENGINEER OFFICE FORTRAN CODE (SOIL EVAPORATION
C     DURING THE PERIOD OF PRE-PLANT IRRIGATION IS NOT ASSUMED EQUAL TO WATER
C     CONSUMPTION COMPUTED FOR A CERTAIN CROP GROWTH). THE MAIN PROGRAM PERMITS
C     THE COMPUTATION OF CROP IRRIGATION USES FOR SEVERAL IRRIGATED AREAS AND
C     MULTIPLE YEARS IN A SINGLE RUN FILE. THIS ACCOMODATES A DETERMINATION AND
C     SUMMARY OF CROP IRRIGATION DEPLETIONS BASIN-WIDE, AND THE MAINTENANCE OF
C     DATA BASES ON HISTORIC IRRIGATION DEPLETIONS THAT CAN BE USED FOR COMPACT
C     ACCOUNTING OF CONSUMPTIVE USES, WATER RIGHTS ADMINISTRATION AND HYDROLOGIC
C     MODELING. THE USER ELECTS WHETHER TO PRINT DETAILED CONSUMPTIVE IRRIGATION
C     REQUIREMENT CALCULATIONS BY CROP FOR EACH IRRIGATION AREA AND YEAR, ANNUAL
C     SUMMARIES GIVING AN ACCOUNTING OF CROP CONSUMPTIVE USES AND TOTAL
C     IRRIGATION DEPLETIONS BY IRRIGATION AREAS AND GEOGRAPHIC REGIONS,
C     MONTHLY IRRIGATION DEPLETIONS AND IRRIGATED ACRES FOR EACH IRRIGATION AREA,
C     AND/OR ALFALFA FUNCTION ANNUAL SUMMARY SHOWING ALFALFA YIELD, YIELD FUNCTION
C     CU AND CIR, FOR USE IN HYDROLOGIC MODELS OR STUDIES. WHEN ALFALFA FUNCTION IS
C     USED, CROP CU IN ANNUAL SUMMARY IS ADJUSTED FOR ALFALFA FUNCITON.
C
C     THIS PROGRAM CAN BE USED TO COMPUTE MONTHLY AND ANNUAL CROP IRRIGATION
C     CONSUMPTIVE USES AND IRRIGATION DEPLETIONS FOR UP TO 50 IRRIGATED AREAS,
C     SUMMED OVER UP TO 20 GEOGRAPHIC REGIONS, AND FOR UP TO 100 YEARS. THE USER
C     MAY REQUEST CONSUMPTIVE USES FOR UP TO 30 CROPS, FOR WHICH THE CROP NAMES
C     AND CROP COEFFICIENTS (K AND Kc) ARE INPUT BY THE USER. FOR THE ORIGINAL
C     BLANEY-CRIDDLE METHOD, K VALUES FOR WINTER WHEAT ARE INPUT FOR THE FALL
C     AND SPRING GROWTH PERIODS, RATHER THAN FOR OUTSIDE AND INSIDE THE FROST-
C     FREE PERIOD, AS RECOMMENDED BY BLANEY (NEW MEXICO STATE ENGINEER TECHNICAL
C     REPORT 32, 1965). FOR THE SCS MODIFIED BLANEY-CRIDDLE METHOD, CROP GROWTH
C     STAGE CURVES ARE DEFINED BY INPUTING THE CURVE VALUES AT THE BEGINNING AND
C     MIDDLE OF EACH MONTH FOR PERENNIAL CROPS, AND AT 5 PERCENT INCREMENTS OF
C     THE GROWING SEASON FOR ANNUAL CROPS. THIS PROGRAM ALSO COMPUTES THE ANNUAL
C     CONSUMPTIVE USES FOR IRRIGATED AREAS WEIGHTED BY CROP TYPE. IN ADDITION,
C     CONSERVATION RESERVE ACREAGE MAY BE INPUT BY THE USER FOR EACH AREA, AND
C     THE SPECIFIED ANNUAL RATES OF APPLICATION OF WATER TO THE RESERVE ACREAGE
C     TO MAINTAIN GROUND COVER IS ASSUMED TO BE FULLY DEPLETED. WEATHER DATA MAY
C     BE ENTERED FOR UP TO 25 WEATHER STATIONS, AND THE USER SPECIFIES WHICH
C     STATION DATA TO USE FOR EACH IRRIGATED AREA.

C     LL    =LINES PER PAGE TO PRINT AREA CU SUMMARIES AND DEPLETIONS OUTPUT
C     LP    =LINES PER PAGE TO PRINT CROP DETAIL AND ALFALFA FUNCTION OUTPUT
C     MBD   =DAY OF PLANTING FOR A CROP, AREA AND YEAR
C     MBEGD =ARRAY OF DAYS OF PLANTING FOR EACH CROP, AREA AND YEAR
C     MBEGM =ARRAY OF MONTHS OF PLANTING FOR EACH CROP, AREA AND YEAR

C     MDF32 =DAY OF FALL 32-DEGREE FROST DATE FOR A WEATHER STATION
C     MDS28 =DAY OF SPRING 28-DEGREE FROST DATE FOR A WEATHER STATION

C     MENDD =ARRAY OF DAYS OF HARVEST/SUPPLY CUTOFF DATES FOR EACH CROP/AREA/YR
C     MENDM =ARRAY OF MONTHS OF HARVEST/SUPPLY CUTOFF DATES FOR EA CROP/AREA/YR
C     MFLAG =ARRAY OF CONTROL FLAGS FOR CU COMPUTATION METHODS
C     MFM28 =ARRAY OF MONTHS/DAYS FOR SPRING 28-D FRSOT DATES FOR EACH AREA/YR
C     MFM32 =ARRAY OF MONTHS/DAYS FOR SPRING 32-D FRSOT DATES FOR EACH AREA/YR
C     MMF28 =MONTH OF FALL 28-DEGREE FROST DATE FOR A WEATHER STATION
C     MMF32 =MONTH OF FALL 32-DEGREE FROST DATE FOR A WEATHER STATION
C     MMS28 =MONTH OF SPRING 28-DEGREE FROST DATE FOR A WEATHER STATION
C     MMS32 =MONTH OF SPRING 32-DEGREE FROST DATE FOR A WEATHER STATION
C     MNF28 =ARRAY OF MONTHS/DAYS FOR FALL 28-D FROST DATES FOR EACH STATION/YR 
C     MNF32 =ARRAY OF MONTHS/DAYS FOR FALL 32-D FROST DATES FOR EACH STATION/YR
C     MNS28 =ARRAY OF MONTHS/DAYS FOR SPRING 28-D FROST DATES FOR EACH STA/YR
C     MNS32 =ARRAY OF MONTHS/DAYS FOR SPRING 32-D FROST DATES FOR EACH STA/YR
C     MON   =ARRAY OF NAMES OF EACH MONTH
C     MSM28 =ARRAY OF MONTHS/DAYS FOR SPRING 28-D FRSOT DATES FOR EACH AREA/YR
C     MSM32 =ARRAY OF MONTHS/DAYS FOR SPRING 32-D FRSOT DATES FOR EACH AREA/YR
C     NA    =AREA IDENTIFICATION NUMBER
C     NALF  =CROP NUMBER INDEX FOR ALFALFA
C     NALFS =CROP NUMBER INDEX FOR SHORTED ALFALFA
C     NAREAS=NUMBER OF IRRIGATED AREAS
C     NCROPS=ARRAY OF NUMBER OF CROPS FOR EACH IRRIGATED AREA
C     NDYRS =NUMBER OF YEARS OF CROP ACREAGE AND WEATHER DATA IN INPUT FILES
C     NPSTA =INDEX ARRAY OF PRECIPITATION STATION NUMBERS ASSOCIATED WITH AREAS
C     NREGS =NUMBER OF GEOGRAPHICAL REGIONS
C     NTSTA =INDEX ARRAY OF TEMPERATURE STATION NUMBERS ASSOCIATED WITH AREAS
C     NTYPES=TOTAL NUMBER OF CROP TYPES
C     NUMYRS=NUMBER OF YEARS FOR ANALYSIS
C     NWSTAS=NUMBER OF WEATHER STATIONS
C     OFILE1=NAME OF CROP WATER USE DETAIL OUTPUT FILE
C     OFILE2=NAME OF CONSUMPTIVE USE ACCOUNTING SUMMARY OUTPUT FILE
C     OFILE3=NAME OF IRRIGATION DEPLETION MODELING DATA OUTPUT FILE
C     OFILE4=NAME OF ALFALFA CROP PRODUCTION FUNCTION RESULTS OUTPUT FILE
C     P     =ARRAY OF PRECIPITATION AMOUNTS FOR EACH MONTH
C     PD    =ARRAY OF WEIGHTED PERCENT DAYLIGHT HOURS FOR EACH IRRIGATED AREA/MO
C     PIMETH=ARRAY OF ACREAGE FRACTIONS FOR EACH IRRIGATED AREA/YEAR/METHOD
C     PM    =ARRAY OF ACREAGE PERCENTAGES FOR EACH IRRIGATION METHOD
C     PREC  =ARRAY OF PRECIPITATION AMOUNTS FOR EACH WEATHER STATION/YEAR/MONTH
C     PRECA =ARRAY OF WEIGHTED PRECIPITATION AMOUNTS FOR EACH AREA/YEAR/MONTH
C     PRSHOR=ANNUAL PERCENTAGE SHORTAGE FOR A REGION
C     PS    =ARRAY OF MONTHLY PERCENTAGE SHORTAGES
C     PSHORT=ARRAY OF MONTHLY PERCENTAGE SHORTAGES FOR EACH IRRIGATED AREA/YEAR
C     REBC  =ARRAY OF MONTHLY EFFECTIVE RAINFALL FROM BLANEY-CRIDDLE METHODOLOGY
C     REGION=ARRAY OF GEOGRAPHICAL OR REGIONAL LOCATION NAMES OF IRRIGATED AREAS
C     SHORT =ARRAY OF ANNUAL CU SHORTAGES FOR EACH IRRIGATED AREA AND YEAR
C     SLMN32=ARRAY OF SPRING LAST DAYS OF MINIMUM 32 DEGREES FOR EACH STA/YEAR 
C     SM32  =LAST JULIAN DAY IN SPRING OF MINIMUM 32 DEGREES OR BELOW
C     T     =ARRAY OF AVERAGE TEMPERATURES FOR EACH MONTH
C     TAC   =TOTAL PLANTED AND IRRIGATED ACREAGE FOR A CROPPING PATTERN
C     TACRE =ARRAY OF TOTAL IRRIGATED ACREAGE FOR EACH IRRIGATED AREA AND YEAR
C     TA1   =ARRAY OF MEAN JAN. TEMPS FOLLOWING LAST COMPUTATION YEAR FOR AREAS
C     TA1S  =ARRAY OF MEAN JAN. TEMPS FOLLOWING LAST DATA YEAR FOR EACH STATION
C     TB12  =ARRAY OF MEAN DEC. TEMPS PRECEDING FIRST COMPUTATION YEAR FOR AREAS 
C     TB12S =ARRAY OF MEAN DEC. TEMPS PRECEDING FIRST DATA YEAR FOR EACH STATION 
C     TCIRM =ARRAY OF ANNUAL CIR'S FROM MODIFIED BC METHOD FOR EACH CROP
C     TCIRO =ARRAY OF ANNUAL CIR'S FROM ORIGINAL BC METHOD FOR EACH CROP
C     TCMIX =ARRAY OF CROP MIX PERCENTAGES
C     TCUFS =ARRAY OF ANNUAL FULL SUPPLY CONSUMPTIVE USE FOR EACH AREA AND YEAR
C     TCUWS =ARRAY OF ANNUAL SHORTED CONSUMPTIVE USE FOR EACH IRRIGATED AREA/YR
C     TDCON =ARRAY OF ANNUAL DEPLETION FOR CONSERVATION ACREAGE AREA/YEAR
C     TDIRR =ARRAY OF ANNUAL IRRIGATION DEPLETIONS FOR EACH IRRIGATED AREA/YEAR
C     TEM   =ARRAY OF MONTHLY TEMP AT WHICH EARLIEST MOISTURE USE OCCURS BY CROP
C     TEMP  =ARRAY OF AVERAGE TEMPERATURES FOR EACH WEATHER STATION/YEAR/MONTH
C     TEMPA =ARRAY OF WEIGHTED AVERAGE TEMPERATURES FOR EACH AREA/YEAR/MONTH
C     TITLE =TITLE OF THE SPECIFIC PROGRAM EXECUTION
C     TRCUFS=TOTAL ANNUAL CONSUMPTIVE USE (FULL SUPPLY) FOR A REGION
C     TRCUWS=TOTAL ANNUAL CONSUMPTIVE USE (SHORTED) FOR A REGION
C     TRDEPI=TOTAL ANNUAL INCIDENTAL DEPLETIONS FOR A REGION
C     TRDIRR=TOTAL ANNUAL IRRIGATION DEPLETIONS FOR A REGION
C     TLM   =ARRAY OF MONTHLY TEMP AT WHICH LATEST MOISTURE USE OCCURS BY CROP
C     TRSHOR=TOTAL ANNUAL SHORTAGE TO CONSUMPTIVE USE FOR A REGION
C     TRACRE=TOTAL IRRIGATED ACREAGE FOR A REGION
C     TRSHOR=TOTAL ANNUAL CU SHORTAGE FOR A REGION
C     UALF  =ANNUAL CONSUMPTIVE USE FOR ALFALFA (FS/SS) FROM PRODUCTION FUNCTION
C     UBC   =ARRAY OF MONTHLY CU FOR ALFALFA FROM BLANEY-CRIDDLE METHODOLOGY
C     UBCT  =ANNUAL CONSUMPTIVE USE FOR ALFALFA FROM BLANEY-CRIDDLE METHODOLOGY
C     WCIR  =ARRAY OF ADJUSTED WEIGHTED ANNUAL CIR'S FOR EACH IRRIGATED AREA/YR
C     WRCIR =WEIGHTED ANNUAL CIR FOR A REGION
C     WSFILE=NAME OF WEATHER STATION DATA FILE
C     WSTIT =ARRAY OF NAMES OF WEATHER STATIONS
C     WWPA  =ACRES OF WINTER WHEAT PLANTED IN LAST DATA YEAR FOR HARVEST NEXT YR
C     WWPLY =ARRAY OF ACRES OF WINTER WHEAT PLANTED LAST COMPUTATION YR FOR AREA
C     XLAT  =LATITUDE IN DECIMAL FORM FOR A WEATHER STATION
C     Y1,Y2 =ANNUAL CROP YIELDS FOR ALFALFA (FULL SUPPLY AND SHORTED)
C     YIELD =ARRAY OF ANNUAL YIELDS FOR ALFALFA (FS/SS) FOR EACH AREA AND YEAR
C
C     DATA DECLARATIONS
C
      REAL CACRE(50,100,30),TCMIX(30),TACRE(50,100),DOUBC(50,100),
     1  CMIX(50,100,30),PSHORT(50,100,12),PM(3),PIMETH(50,100,3),
     2  DEPIF(50,100,3),DF(3),YIELD(50,100,2),APPDEP(50,100),
     3  PREC(25,100,12),ALAT(50),DHR(25,12),DLAT(25),TEMP(25,100,12),
     4  TEM(30),TLM(30),CIFF(30),COFF(30),GSL(30),T(12),P(12),TB12(50),
     5  C(30,2,25),DL(26),D(26,12),PRECA(50,100,12),TEMPA(50,100,12),
     6  PD(50,12),DAYS(12),CIROBC(30,12),CIRMBC(30,12),TCIRO(30),
     7  TCIRM(30),REBC(2,12),UBC(2,12),WCIR(50,100),CUFS(50,100,12),
     8  TA1(50),TCUFS(50,100),SHORT(50,100),PS(12),
     9  UALF(2),TCUWS(50,100),DEPINC(50,100),
     1  TDIRR(50,100),ACL(20,100),CIRM(12),DEPIRR(50,100,12),DEPMO(12),
     2  CONRES(50,100),CONAPP(50,100),TDCON(50,100),TB12S(25),TA1S(25),
     3  WWPLY(50)
      INTEGER NYR(100),MFLAG(4),NCROPS(50),NPSTA(50),NTSTA(50),IREG(50),
     1  ICROPS(50,100),IOUT(4),MNS28(2,25,100),MNS32(2,25,100),
     2  MNF32(2,25,100),MNF28(2,25,100),MSM28(2,50,100),MSM32(2,50,100),
     3  MFM32(2,50,100),MFM28(2,50,100),MBEGM(50,30,100),
     4  MBEGD(50,30,100),MENDM(50,30,100),MENDD(50,30,100),ICA(50)
      DIMENSION ARNAME(50),CRTIT(30),WSTIT(25),CTYPE(30),MON(13),
     1  REGION(20)
      CHARACTER INFILE*80,OFILE1*80,OFILE2*80,OFILE3*80,OFILE4*80,
     1  TITLE*80,MON*3,BCFILE*80,WSFILE*80,CCFILE*80,ARNAME*40,CRTIT*24,
     2  WSTIT*40,EP*4,CTYPE*2,REGION*40
      COMMON/BLKCIR/ CACRE,TACRE,DOUBC,CMIX,APPDEP,GSL,TEM,TLM,C,CIFF,
     1  COFF,PRECA,TEMPA,TB12,TA1,PD,CIROBC,CIRMBC,TCIRO,TCIRM,REBC,UBC,
     2  NYR,NCROPS,NPSTA,NTSTA,ICROPS,NALF,NALFS,IREG,IOUT,MSM28,MSM32,
     3  MFM32,MFM28,MBEGM,MBEGD,MENDM,MENDD,NUMYRS,TITLE,MON,ARNAME,
     4  CRTIT,WSTIT,CTYPE,REGION,LP,LL
      COMMON/BLKDAY/ DAYS
C
C     INITIALIZE MONTH AND DAYS ARRAYS
C
      MON(1)='JAN'
      MON(2)='FEB'
      MON(3)='MAR'
      MON(4)='APR'
      MON(5)='MAY'
      MON(6)='JUN'
      MON(7)='JUL'
      MON(8)='AUG'
      MON(9)='SEP'
      MON(10)='OCT'
      MON(11)='NOV'
      MON(12)='DEC'
      MON(13)='N/A'
      DAYS(1)=31.
      DAYS(2)=28.
      DAYS(3)=31.
      DAYS(4)=30.
      DAYS(5)=31.
      DAYS(6)=30.
      DAYS(7)=31.
      DAYS(8)=31.
      DAYS(9)=30.
      DAYS(10)=31.
      DAYS(11)=30.
      DAYS(12)=31.
C
C     OPEN INPUT CONTROL FILE
C
      WRITE(*,10)
   10 FORMAT(/' ENTER CONSUMPTIVE USE PROGRAM CONTROL FILE NAME:')
      READ(*,20) INFILE
   20 FORMAT(A80)
21	format(2x,a80)
      WRITE(*,30)
   30 FORMAT(/' PROGRAM IS EXECUTING'/)
      OPEN(15,FILE=INFILE,STATUS='OLD')
      READ(15,20) TITLE
      WRITE(*,21) TITLE
C
C     OPEN CROP ACREAGE, WEATHER STATION AND CROP COEFFICIENT DATA FILES
C
      READ(15,20) BCFILE,WSFILE,CCFILE
      WRITE(*,40)
   40 FORMAT(/' INPUT FILES:'/)
      WRITE(*,21) BCFILE,WSFILE,CCFILE
      OPEN(7,FILE=BCFILE,STATUS='OLD')
      OPEN(8,FILE=WSFILE,STATUS='OLD')
      OPEN(9,FILE=CCFILE,STATUS='OLD')
C
C     OPEN OUTPUT FILES
C
      READ(15,50) (IOUT(I),I=1,4),LP,LL
   50 FORMAT(10I8)
      READ(15,20) OFILE1
      IF(IOUT(1).GT.0) OPEN(10,FILE=OFILE1,STATUS='NEW')
      READ(15,20) OFILE2
      IF(IOUT(2).GT.0) OPEN(11,FILE=OFILE2,STATUS='NEW')
      READ(15,20) OFILE3
      IF(IOUT(3).GT.0) OPEN(12,FILE=OFILE3,STATUS='NEW')
      READ(15,20) OFILE4
      IF(IOUT(4).GT.0) OPEN(13,FILE=OFILE4,STATUS='NEW')
      WRITE(*,60)
   60 FORMAT(/' OUTPUT FILES:'/)
      WRITE(*,21) OFILE1,OFILE2,OFILE3,OFILE4
      IF(LP.LE.0) LP=64
      IF(LL.LE.0) LL=45
C
C     READ CONTROL DATA FOR NUMBERS OF YEARS, AREAS AND WEATHER STATIONS
C
      READ(15,50) IBYR,IEYR,NREGS,NAREAS,NWSTAS,IDBYR,IDEYR
      NYR(1)=IBYR
      NUMYRS=IEYR-IBYR+1
      NDYRS=IDEYR-IDBYR+1
      IF(IEYR.LE.IBYR) GO TO 80
      DO 70 I=2,NUMYRS
      NYR(I)=NYR(I-1)+1
   70 CONTINUE
C
C     READ METHODOLOGY CONTROL FLAGS - SELECT CU METHOD (ORIGINAL B-C METHOD OR
C     MODIFIED B-C METHOD, WITH OR WITHOUT ALFALFA CROP PRODUCTION FUNCTION),
C     AND EFFECTIVE RAINFALL METHOD (USBR OR SCS)
C     [NOTE: IF BOTH ORIGINAL AND MODIFIED B-C METHOD CHOSEN, ANNUAL CU COMPUTED
C     USING ORIGINAL B-C METHOD WILL BE DISTRIBUTED MONTHLY BASED ON MODIFIED
C     B-C METHOD MONTHLY DISTRIBUTION]
C
   80 READ(15,50) (MFLAG(K),K=1,4)
      CLOSE(5)
C
C     READ CROP AND WEATHER STATION INDEX DATA FOR IRRIGATED AREA
C
      READ(7,90) (REGION(I),I=1,NREGS)
   90 FORMAT(8X,A40)
      DO 210 I=1,NAREAS
      READ(7,90) ARNAME(I)
      READ(7,100) ALAT(I)
  100 FORMAT(10F8.2)
      READ(7,50) IREG(I),NCROPS(I),NPSTA(I),NTSTA(I)
      READ(7,50) (ICROPS(I,J),J=1,NCROPS(I))
C
C     READ CROP ACREAGE DATA FOR IRRIGATED AREA
C
      IC=0
      READ(7,100) WWPA
      DO 150 J=1,NDYRS
      READ(7,110) IYR,TAC,DCROP,CONSR,CONSAP,Y1,Y2
  110 FORMAT(I8,9F8.2)
      READ(7,100)(TCMIX(K),K=1,NCROPS(I))
      IF((IYR.LT.IBYR).OR.(IYR.GT.IEYR)) GO TO 130
      IC=IC+1
      DOUBC(I,IC)=DCROP
      TACRE(I,IC)=TAC-DCROP
      YIELD(I,IC,1)=Y1
      YIELD(I,IC,2)=Y2
      CONRES(I,IC)=CONSR
      CONAPP(I,IC)=CONSAP
      DO 120 K=1,NCROPS(I)
      CMIX(I,IC,K)=TCMIX(K)/100.
      CACRE(I,IC,K)=(TACRE(I,IC)+DOUBC(I,IC))*TCMIX(K)/100.
      IF(CTYPE(ICROPS(I,K)).NE.'WG') GO TO 120
  120 CONTINUE
      IF(IYR.EQ.IDEYR) WWPLY(I)=WWPA
      GO TO 150
  130 IF((IYR-1).NE.IEYR) GO TO 150
      DO 140 K=1,NCROPS(I)
      IF(CTYPE(ICROPS(I,K)).EQ.'WG') WWPLY(I)=TAC*TCMIX(K)/100.
  140 CONTINUE
  150 CONTINUE
C
C     READ ACREAGE FRACTIONS AND INCIDENTAL DEPLETION PERCENTAGE FACTORS FOR
C     FLOOD, SPRINKLER AND DRIP IRRIGATION METHODS, AND IRRIGATION APPLICATION
C     DEPTHS, FOR IRRIGATED AREA
C
      IC=0
      DO 170 J=1,NDYRS
      READ(7,110) IYR,(PM(K),DF(K),K=1,3),AD
      IF((IYR.LT.IBYR).OR.(IYR.GT.IEYR)) GO TO 170
      IC=IC+1
      IF(AD.LE.0.) AD=3.
      APPDEP(I,IC)=AD
      DO 160 K=1,3
      PIMETH(I,IC,K)=PM(K)/100.
      DEPIF(I,IC,K)=DF(K)/100.
  160 CONTINUE
  170 CONTINUE
C
C     READ WATER SUPPLY PERCENTAGE SHORTAGE DATA, IF ANY, FOR IRRIGATED AREA
C
      DO 180 J=1,NDYRS
      DO 175 K=1,12
      PSHORT(I,J,K)=0.
  175 CONTINUE
  180 CONTINUE
      READ(7,50) KFLAG
      IF(KFLAG.LE.0) GO TO 210
      IC=0
      DO 200 J=1,NDYRS
      READ(7,310) IYR,(PS(K),K=1,12)
  185 CONTINUE
      IF((IYR.LT.IBYR).OR.(IYR.GT.IEYR)) GO TO 200
      IC=IC+1
      DO 195 K=1,12
      PSHORT(I,IC,K)=PS(K)
  195 CONTINUE
  200 CONTINUE
  210 CONTINUE
C
C     READ LATITUDE-DAYLIGHT HOURS FUNCTION
C
      DO 230 L=1,26
      READ(7,220,END=240) DL(L),(D(L,J),J=1,12)
  220 FORMAT(13F6.2)
  230 CONTINUE
  240 CLOSE(7)
C
C     COMPUTE MONTHLY PERCENTAGE DAYLIGHT HOURS FOR IRRIGATED AREA IF LATITUDE
C     FOR AREA IS SPECIFIED (RATHER THAN LATITUDE OF ASSOCIATED WEATHER STATION)
C
      DO 270 I=1,NAREAS
      IF(ALAT(I).LE.0.) GO TO 270
      NLAT=INT(ALAT(I))
      XMIN=((ALAT(I)-REAL(NLAT))*100.)/60.
      XLAT=REAL(NLAT)+XMIN
      DO 260 J=1,26
      IF(XLAT.GT.DL(J)) GO TO 260
      DO 250 K=1,12
      PD(I,K)=(XLAT-DL(J-1))*(D(J,K)-D(J-1,K))/(DL(J)-DL(J-1))+D(J-1,K)
  250 CONTINUE
      GO TO 270
  260 CONTINUE
  270 CONTINUE
C
C     READ WEATHER STATION INFORMATION
C
      DO 390 M=1,NWSTAS
      READ(8,90) WSTIT(M)
      READ(8,50) IPFLAG,ITFLAG
      READ(8,100) DLAT(M)
C
C     COMPUTE MONTHLY PERCENTAGE DAYLIGHT HOURS FOR WEATHER STATION LATITUDE
C
      IF(DLAT(M).LE.0.) GO TO 300
      NLAT=INT(DLAT(M))
      XMIN=((DLAT(M)-REAL(NLAT))*100.)/60.
      XLAT=REAL(NLAT)+XMIN
      DO 290 J=1,26
      IF(XLAT.GT.DL(J)) GO TO 290
      DO 280 K=1,12
      DHR(M,K)=(XLAT-DL(J-1))*(D(J,K)-D(J-1,K))/(DL(J)-DL(J-1))+D(J-1,K)
  280 CONTINUE
      GO TO 300
  290 CONTINUE
C
C     READ PRECIPITATION DATA
C
  300 IF(IPFLAG.LE.0) GO TO 340
      IC=0
      DO 330 J=1,NDYRS
      READ(8,310) IYR,(P(K),K=1,12)
  310 FORMAT(I8,12F6.2)
      IF((IYR.LT.IBYR).OR.(IYR.GT.IEYR)) GO TO 330
      IC=IC+1
      DO 320 K=1,12
      PREC(M,IC,K)=P(K)
  320 CONTINUE
  330 CONTINUE
C
C     READ TEMPERATURE DATA
C
  340 IF(ITFLAG.LE.0) GO TO 390
      READ(8,100) TB12S(M),TA1S(M)
      IC=0
      DO 370 J=1,NDYRS
      READ(8,310) IYR,(T(K),K=1,12)
      IF((IYR.LT.IBYR).OR.(IYR.GT.IEYR)) GO TO 360
c      WRITE(*,*)IYR,(T(K),K=1,12)
      IC=IC+1
      DO 350 K=1,12
      TEMP(M,IC,K)=T(K)
c     WRITE(*,*)TEMP(M,IC,K),'TEMP'
  350 CONTINUE
      IF(IYR.NE.IBYR) GO TO 370
      IF((IYR.GT.IDBYR).AND.(IYR.NE.IEYR)) TB12S(M)=T(12)
      WRITE(*,*)TB12S(M),'TBS'
      GO TO 370
  360 IF((IYR-1).EQ.IEYR) TA1S(M)=T(1)
  370 CONTINUE
      IC=0
      DO 380 J=1,NDYRS
      READ(8,50) IYR,MMS28,MDS28,MMS32,MDS32,MMF32,MDF32,MMF28,MDF28
      IF((IYR.LT.IBYR).OR.(IYR.GT.IEYR)) GO TO 380
      IC=IC+1
      MNS28(1,M,IC)=MMS28
      MNS28(2,M,IC)=MDS28
      MNS32(1,M,IC)=MMS32
      MNS32(2,M,IC)=MDS32
      MNF32(1,M,IC)=MMF32
      MNF32(2,M,IC)=MDF32
      MNF28(1,M,IC)=MMF28
      MNF28(2,M,IC)=MDF28
  380 CONTINUE
  390 CONTINUE
      CLOSE(8)
C
C     ASSIGN WEATHER STATION DATA TO IRRIGATED AREAS
C
      DO 430 I=1,NAREAS
      TB12(I)=TB12S(NPSTA(I))
      TA1(I)=TA1S(NPSTA(I))
      DO 410 J=1,NUMYRS
      DO 400 K=1,12
      PRECA(I,J,K)=PREC(NPSTA(I),J,K)
      TEMPA(I,J,K)=TEMP(NTSTA(I),J,K)
      IF(K.GT.2) GO TO 400
      MSM28(K,I,J)=MNS28(K,NTSTA(I),J)
      MSM32(K,I,J)=MNS32(K,NTSTA(I),J)
      MFM32(K,I,J)=MNF32(K,NTSTA(I),J)
      MFM28(K,I,J)=MNF28(K,NTSTA(I),J)
  400 CONTINUE
  410 CONTINUE
      IF(ALAT(I).GT.0.) GO TO 430
      DO 420 K=1,12
      PD(I,K)=DHR(NTSTA(I),K)
  420 CONTINUE
  430 CONTINUE
C
C     READ CROP IDENTIFICATION, COEFFICIENTS AND GROWTH SEASON LENGTHS
C
      READ(9,50) NTYPES,NALF,NALFS
      DO 500 I=1,NTYPES
      READ(9,440) CRTIT(I)
  440 FORMAT(2X,A24)
      READ(9,450) CTYPE(I),TEM(I),TLM(I),CIFF(I),COFF(I),GSL(I)
  450 FORMAT(A2,4X,5F6.2)
      READ(9,220) (C(I,1,J),J=1,25)
      READ(9,220) (C(I,2,J),J=1,25)
C
C     READ BEGINNING AND END DATES FOR GROWING SEASON, IF ANY, SPECIFIED BY USER
C
      DO 470 J=1,NAREAS
      ICA(J)=0.
      DO 460 K=1,NDYRS
      MBEGM(J,I,K)=0
      MBEGD(J,I,K)=0
      MENDM(J,I,K)=0
      MENDD(J,I,K)=0
  460 CONTINUE
  470 CONTINUE
      READ(9,50) IFL
      IF(IFL.LE.0) GO TO 500
      DO 490 J=1,NAREAS
      DO 480 K=1,NDYRS
      READ(9,50) NA,IYR,MBM,MBD,MEM,MED
      IF(NA.LE.0) GO TO 500
      IF((IYR.LT.IBYR).OR.(IYR.GT.IEYR)) GO TO 480
      ICA(NA)=ICA(NA)+1
      MBEGM(NA,I,ICA(NA))=MBM
      MBEGD(NA,I,ICA(NA))=MBD
      MENDM(NA,I,ICA(NA))=MEM
      MENDD(NA,I,ICA(NA))=MED
  480 CONTINUE
  490 CONTINUE
  500 CONTINUE
      CLOSE(9)
C
C     PERFORM CIR AND CONSUMPTIVE USE COMPUTATIONS
C
      DO 850 I=1,NAREAS
      DO 840 J=1,NUMYRS
      DO 520 L=1,NCROPS(I)
      DO 510 K=1,12
      CIROBC(L,K)=0.
      CIRMBC(L,K)=0.
  510 CONTINUE
  520 CONTINUE
      IAL=0
      IALS=0
C
C     USE ORIGINAL BLANEY-CRIDDLE METHOD
C
      IF(MFLAG(1).LE.0) GO TO 570
      CALL CIRCAL(I,J,1,MFLAG(4))
C
C     ADJUST ORIGINAL B-C METHOD ALFALFA CIR FOR THE ALFALFA PRODUCTION FUNCTION
C     IF THE FUNCTION GIVES A GREATER ANNUAL CIR FOR ALFALFA, IF SELECTED
C
      IF(MFLAG(3).LE.0) GO TO 570
      DO 560 IM=1,NCROPS(I)
      IF((ICROPS(I,IM).NE.NALF).AND.(ICROPS(I,IM).NE.NALFS)) GO TO 560
      IF(ICROPS(I,IM).EQ.NALF) THEN
      IAL=IM
      M=1
      ENDIF
      IF(ICROPS(I,IM).EQ.NALFS) THEN
      IALS=IM
      M=2
      ENDIF
      IF(YIELD(I,J,M).GT.0) THEN
      UALF(M)=(YIELD(I,J,M)+0.5904)/0.1572
      ENDIF
      IF(YIELD(I,J,M).LE.0) THEN
      UALF(M)=0.
      ENDIF
      UBCT=0.
      DO 530 K=1,12
      UBCT=UBCT+UBC(M,K)
  530 CONTINUE
      TCIR=0.
      DO 540 K=1,12
      U=UALF(M)*UBC(M,K)/UBCT
      IF(REBC(M,K).GT.U) REBC(M,K)=U
      CIRM(K)=U-REBC(M,K)
      IF(CIRM(K).LE.0.) CIRM(K)=0.
      TCIR=TCIR+CIRM(K)
  540 CONTINUE
      IF(TCIRO(IM).GE.TCIR) GO TO 560
      DO 550 K=1,12
      CIROBC(IM,K)=CIRM(K)
  550 CONTINUE
      TCIRO(IM)=TCIR
  560 CONTINUE
C
C     USE SCS MODIFIED BLANEY-CRIDDLE METHOD
C
  570 IF(MFLAG(2).LE.0) GO TO 620
      CALL CIRCAL(I,J,2,MFLAG(4))
C
C     ADJUST MODIFIED B-C METHOD ALFALFA CIR FOR THE ALFALFA PRODUCTION FUNCTION
C     IF THE FUNCTION GIVES A GREATER ANNUAL CIR FOR ALFALFA, IF SELECTED
C
      IF(MFLAG(3).LE.0) GO TO 620
      DO 610 IM=1,NCROPS(I)
      IF((ICROPS(I,IM).NE.NALF).AND.(ICROPS(I,IM).NE.NALFS)) GO TO 610
      IF(ICROPS(I,IM).EQ.NALF) THEN
      IAL=IM
      M=1
      ENDIF
      IF(ICROPS(I,IM).EQ.NALFS) THEN
      IALS=IM
      M=2
      ENDIF
      IF(YIELD(I,J,M).GT.0) THEN
      UALF(M)=(YIELD(I,J,M)+0.5904)/0.1572
      ENDIF
      IF(YIELD(I,J,M).LE.0) THEN
      UALF(M)=0.
      ENDIF
      UBCT=0.
      DO 580 K=1,12
      UBCT=UBCT+UBC(M,K)
  580 CONTINUE
      TCIR=0.
      DO 590 K=1,12
      U=UALF(M)*UBC(M,K)/UBCT
      IF(REBC(M,K).GT.U) REBC(M,K)=U
      CIRM(K)=U-REBC(M,K)
      IF(CIRM(K).LE.0.) CIRM(K)=0.
      TCIR=TCIR+CIRM(K)
  590 CONTINUE
      IF(TCIRM(IM).GE.TCIR) GO TO 610
      DO 600 K=1,12
      CIRMBC(IM,K)=CIRM(K)
  600 CONTINUE
      TCIRM(IM)=TCIR
  610 CONTINUE
C
C     PRINT ALFALFA CONSUMPTIVE USE DETAILS FROM PRODUCTION FUNCTION, IF
C     REQUESTED
C
  620 IF((IOUT(4).LE.0).OR.(MFLAG(3).LE.0)) GO TO 690
      IF(MFLAG(4).LE.0) EP='  NO'
      IF(MFLAG(4).EQ.1) EP='USBR'
      IF(MFLAG(4).GE.2) EP=' SCS'
      IF(J.EQ.1) THEN
      WRITE(13,630) EP,EP,TITLE,ARNAME(I)
  630 FORMAT(10X,'ALFALFA CROP PRODUCTION FUNCTION RESULTS'/1X,'(CIR1 ',
     1  'IS FROM ORIGINAL B-C METHOD MONTHLY CU DISTRIBUTION AND ',A4,
     2  ' EFFECTIVE PRECIP,'/1X,'CIR2 IS FROM SCS MODIFIED B-C METHOD',
     3  ' MONTHLY CU DISTRIBUTION AND ',A4,' EFFECTIVE PRECIP)'//1X,A80/
     4  1X,'IRRIGATED AREA: ',A40//1X,'YEAR',3X,'YIELD (T/AC)',8X,
     5  'CU (IN)',3X,'CIR1 (IN/YR)',3X,'CIR2 (IN/YR)'/1X,80('=')/)
      LCTR=10
      ENDIF
      IF((MFLAG(1).GT.0).AND.(MFLAG(2).GT.0).AND.(IAL.GT.0.))
     1   THEN
      WRITE(13,640) NYR(J),YIELD(I,J,1),UALF(1),TCIRO(IAL),TCIRM(IAL)
  640 FORMAT(1X,I4,4(9X,F6.2))
      LCTR=LCTR+1
      ENDIF
      IF((MFLAG(1).GT.0).AND.(MFLAG(2).GT.0).AND.
     1   (IALS.GT.0.)) THEN
      WRITE(13,640) NYR(J),YIELD(I,J,2),UALF(2),TCIRO(IALS),TCIRM(IALS)
      LCTR=LCTR+1
      ENDIF
      IF((MFLAG(1).GT.0).AND.(MFLAG(2).LE.0).AND.(IAL.GT.0.))
     1   THEN
      WRITE(13,650) NYR(J),YIELD(I,J,1),UALF(1),TCIRO(IAL)
  650 FORMAT(1X,I4,3(9X,F6.2))
      LCTR=LCTR+1
      ENDIF
      IF((MFLAG(1).GT.0).AND.(MFLAG(2).LE.0).AND.
     1   (IALS.GT.0.)) THEN
      WRITE(13,650) NYR(J),YIELD(I,J,2),UALF(2),TCIRO(IALS)
      LCTR=LCTR+1
      ENDIF
      IF((MFLAG(2).GT.0).AND.(MFLAG(1).LE.0).AND.(IAL.GT.0.))
     1   THEN
      WRITE(13,660) NYR(J),YIELD(I,J,1),UALF(1),TCIRM(IAL)
  660 FORMAT(1X,I4,2(9X,F6.2),24X,F6.2)
      LCTR=LCTR+1
      ENDIF
      IF((MFLAG(2).GT.0).AND.(MFLAG(1).LE.0).AND.
     1   (IALS.GT.0.)) THEN
      WRITE(13,660) NYR(J),YIELD(I,J,2),UALF(2),TCIRM(IALS)
      LCTR=LCTR+1
      ENDIF
      IF(J.LT.NUMYRS) GO TO 690
      L=LP-MOD(LCTR,LP)
      IF(L.LE.0) GO TO 690
      DO 680 K=1,L
      WRITE(13,670)
  670 FORMAT(' ')
  680 CONTINUE
C
C     COMPUTE CONSUMPTIVE USE FOR IRRIGATED AREA FOR CALENDAR YEAR, INCLUDING
C     FOR FALL PLANT/SPRING HARVEST CROPS
C
  690 IF((IOUT(2).LE.0).AND.(IOUT(3).LE.0)) GO TO 840
      TCUFS(I,J)=0.
      DO 700 K=1,12
      CUFS(I,J,K)=0.
  700 CONTINUE
      IF((MFLAG(1).GT.0).AND.(MFLAG(2).GT.0)) GO TO 780
      IF(MFLAG(2).GT.0) GO TO 740
C
C     CONSUMPTIVE USE BASED ON APPLICATION OF ORIGINAL BLANEY-CRIDDLE METHOD
C
      DO 730 K=1,12
      DO 720 IM=1,NCROPS(I)
      IF((CTYPE(ICROPS(I,IM)).EQ.'WG').AND.(K.GE.9)) GO TO 710
      CUFS(I,J,K)=CUFS(I,J,K)+CIROBC(IM,K)*CACRE(I,J,IM)/12.
      GO TO 720
  710 IF(J.LT.NUMYRS) CUFS(I,J,K)=CUFS(I,J,K)+CIROBC(IM,K)*
     1  CACRE(I,J+1,IM)/12.
      IF(J.GE.NUMYRS) CUFS(I,J,K)=CUFS(I,J,K)+CIROBC(IM,K)*WWPLY(I)/12.
  720 CONTINUE
      TCUFS(I,J)=TCUFS(I,J)+CUFS(I,J,K)
  730 CONTINUE
      GO TO 820
C
C     CONSUMPTIVE USE BASED ON APPLICATION OF SCS MODIFIED BLANEY-CRIDDLE METHOD
C
  740 DO 770 K=1,12
      DO 760 IM=1,NCROPS(I)
      IF((CTYPE(ICROPS(I,IM)).EQ.'WG').AND.(K.GE.9)) GO TO 750
      CUFS(I,J,K)=CUFS(I,J,K)+CIRMBC(IM,K)*CACRE(I,J,IM)/12.
      GO TO 760
  750 IF(J.LT.NUMYRS) CUFS(I,J,K)=CUFS(I,J,K)+CIRMBC(IM,K)*
     1  CACRE(I,J+1,IM)/12.
      IF(J.GE.NUMYRS) CUFS(I,J,K)=CUFS(I,J,K)+CIRMBC(IM,K)*WWPLY(I)/12.
  760 CONTINUE
      TCUFS(I,J)=TCUFS(I,J)+CUFS(I,J,K)
  770 CONTINUE
      GO TO 820
C
C     CONSUMPTIVE USE BASED ON THE ANNUAL CIR COMPUTED USING THE ORIGINAL B-C
C     METHOD AND THE MONTHLY CIR DISTRIBUTION OBTAINED FROM THE SCS MODIFIED B-C
C     METHOD
C
  780 DO 810 K=1,12
      DO 800 IM=1,NCROPS(I)
      IF((CTYPE(ICROPS(I,IM)).EQ.'WG').AND.(K.GE.9)) GO TO 790
      CUFS(I,J,K)=CUFS(I,J,K)+TCIRO(IM)*(CIRMBC(IM,K)/TCIRM(IM))*
     1  CACRE(I,J,IM)/12.
      GO TO 800
  790 IF(J.LT.NUMYRS) CUFS(I,J,K)=CUFS(I,J,K)+TCIRO(IM)*
     1  (CIRMBC(IM,K)/TCIRM(IM))*CACRE(I,J+1,IM)/12.
      IF(J.GE.NUMYRS) CUFS(I,J,K)=CUFS(I,J,K)+TCIRO(IM)*
     1  (CIRMBC(IM,K)/TCIRM(IM))*WWPLY(I)/12.
  800 CONTINUE
      TCUFS(I,J)=TCUFS(I,J)+CUFS(I,J,K)
  810 CONTINUE
C
C     COMPUTE ADJUSTED WEIGHTED ANNUAL CROP CIR
C
  820 WCIR(I,J)=TCUFS(I,J)/TACRE(I,J)
C
C     COMPUTE SHORTAGES AND SHORTED ANNUAL CONSUMPTIVE USES USING INPUT SHORTAGE
C     PERCENTAGES FOR THE IRRIGATED AREA (SHORTAGE AMOUNTS ARE IN ADDITION TO,
C     AND EXCLUDE, ANY USE SHORTAGES IMPOSED IN CROP CIR COMPUTATIONS DUE TO
C     USER-SPECIFIED WATER SUPPLY CUTOFF DATES)
C
      SHORT(I,J)=0.
      TCUWS(I,J)=0.
      DEPINC(I,J)=0.
      DO 835 K=1,12
      SHORT(I,J)=SHORT(I,J)+CUFS(I,J,K)*PSHORT(I,J,K)/100.
      CUWS=CUFS(I,J,K)*(1-(PSHORT(I,J,K)/100.))
      TCUWS(I,J)=TCUWS(I,J)+CUWS
C
C     COMPUTE INCIDENTAL AND TOTAL IRRIGATION DEPLETIONS
C     
      DEPIRR(I,J,K)=CUWS
      DINC=0.
      DO 830 L=1,3
      DINC=CUWS*PIMETH(I,J,L)*DEPIF(I,J,L)
      DEPINC(I,J)=DEPINC(I,J)+DINC
      DEPIRR(I,J,K)=DEPIRR(I,J,K)+DINC
  830 CONTINUE
  835 CONTINUE
C
C     COMPUTE CONSERVATION RESERVE IRRIGATION DEPLETIONS
C
      TDCON(I,J)=CONRES(I,J)*CONAPP(I,J)
C
C     COMPUTE TOTAL IRRIGATION DEPLETIONS (SHORTED)
C
      TDIRR(I,J)=TCUWS(I,J)+DEPINC(I,J)+TDCON(I,J)
  840 CONTINUE
  850 CONTINUE
      IF(IOUT(1).GT.0) CLOSE(10)
      IF(IOUT(4).GT.0) CLOSE(13)
      IF(IOUT(2).LE.0) GO TO 990
C
C     COMPUTE AVERAGE ANNUAL ACREAGE, CIR, CROP CONSUMPTIVE USE, SHORTAGE,
C     INCIDENTAL DEPLETION, CONSERVATION RESERVE DEPLETION AND TOTAL DEPLETION
C     FOR IRRIGATED AREAS
C
      DO 920 I=1,NAREAS
      AVTAC=0.
      AVWCR=0.
      AVCUFS=0.
      AVSHOR=0.
      AVPSOR=0.
      AVCUWS=0.
      AVDEP=0.
      AVCON=0.
      AVDIR=0.
      DO 860 J=1,NUMYRS
      AVTAC=AVTAC+TACRE(I,J)
      AVWCR=AVWCR+WCIR(I,J)
      AVCUFS=AVCUFS+TCUFS(I,J)
      AVSHOR=AVSHOR+SHORT(I,J)
      AVPSOR=AVPSOR+SHORT(I,J)*100./TCUFS(I,J)
      AVCUWS=AVCUWS+TCUWS(I,J)
      AVDEP=AVDEP+DEPINC(I,J)
      AVCON=AVCON+TDCON(I,J)
      AVDIR=AVDIR+TDIRR(I,J)
  860 CONTINUE
      AVTAC=AVTAC/REAL(NUMYRS)
      AVWCR=AVWCR/REAL(NUMYRS)
      AVCUFS=AVCUFS/REAL(NUMYRS)
      AVSHOR=AVSHOR/REAL(NUMYRS)
      AVPSOR=AVPSOR/REAL(NUMYRS)
      AVCUWS=AVCUWS/REAL(NUMYRS)
      AVDEP=AVDEP/REAL(NUMYRS)
      AVCON=AVCON/REAL(NUMYRS)
      AVDIR=AVDIR/REAL(NUMYRS)
C
C     PRINT CONSUMPTIVE USE ACCOUNTING RESULTS BY IRRIGATED AREA
C
      DO 910 J=1,NUMYRS
      PERS=SHORT(I,J)*100./TCUFS(I,J)
      IF(J.EQ.1) WRITE(11,870) TITLE,ARNAME(I)
  870 FORMAT(10X,'ANNUAL IRRIGATION CONSUMPTIVE USES'//1X,A80/1X,
     1  'IRRIGATED AREA: ',A40//,18X,'CROP',7X,'CROP',77X,'TOTAL',/,
     2  16X,'WEIGHTED',4X,'CU FULL',4X,'SHORTAGE',2X,'SHORTAGE',2X,
     3  'CONSUMPTIVE',4X,'INCIDENTAL',6X,'CONSERVATION',7X,
     4  'IRRIGATION'/1X,'YEAR', 4X,'ACRES',2X,'CIR (FT)',2X,
     5  'SUPPLY (AF)',4X,'(AF)',6X,'(%)',6X,'USE (AF)',4X,
     6  'DEPLETIONS (AF)',3X,'DEPLETION (AF)',3X, 'DEPLETION (AF)'/1X,
     7  121('=')/)
      WRITE(11,880) NYR(J),TACRE(I,J),WCIR(I,J),TCUFS(I,J),SHORT(I,J),
     1  PERS,TCUWS(I,J),DEPINC(I,J),TDCON(I,J),TDIRR(I,J)
  880 FORMAT(1X,I4,2X,F7.0,3X,F7.2,6X,F7.0,3X,F7.0,3X,F7.0,6X,F7.0,10X,
     1  F7.0,9X,F7.0,9X,F7.0)
      IF(J.LT.NUMYRS) GO TO 910
      WRITE(11,890) AVTAC,AVWCR,AVCUFS,AVSHOR,AVPSOR,AVCUWS,AVDEP,AVCON,
     1  AVDIR
  890 FORMAT(/'AVERAGE',F7.0,3X,F7.2,6X,F7.0,3X,F7.0,3X,F7.0,6X,F7.0,
     1  10X,F7.0,9X,F7.0,9X,F7.0)
      WRITE(11,895)
  895 FORMAT(/' NOTE:SHORTAGES ARE BASED ON USER-INPUT PERCENTAGES AND'
     1  ' EXCLUDE SHORTAGES AFTER USER-INPUT WATER SUPPLY CUTOFF DATES'/
     2  ' THAT MAY BE USED, FOR EXAMPLE, FOR SHORTED ALFALFA AND'
     3  ' PASTURE.')
      L=LL-MOD((15+NUMYRS),LL)
      IF(L.LE.0) GO TO 910
      DO 900 K=1,L
      WRITE(11,670)
  900 CONTINUE
  910 CONTINUE
  920 CONTINUE
C
C     SUM IRRIGATED ACRES, CROP CONSUMPTIVE USES AND IRRIGATION DEPLETIONS BY
C     REGION
C
      DO 980 I=1,NREGS
      AVTAC=0.
      AVWCR=0.
      AVCUFS=0.
      AVSHOR=0.
      AVPSOR=0.
      AVCUWS=0.
      AVDEP=0.
      AVCON=0.
      AVDIR=0.
      DO 970 J=1,NUMYRS
      TRACRE=0.
      TRCUFS=0.
      TRSHOR=0.
      TRCUWS=0.
      TRDEPI=0.
      TRDCON=0.
      TRDIRR=0.
      DO 930 IM=1,NAREAS
      IF(IREG(IM).NE.I) GO TO 930
      TRACRE=TRACRE+TACRE(IM,J)
      TRCUFS=TRCUFS+TCUFS(IM,J)
      TRSHOR=TRSHOR+SHORT(IM,J)
      TRCUWS=TRCUWS+TCUWS(IM,J)
      TRDEPI=TRDEPI+DEPINC(IM,J)
      TRDCON=TRDCON+TDCON(IM,J)
      TRDIRR=TRDIRR+TDIRR(IM,J)
  930 CONTINUE
      WRCIR=TRCUFS/TRACRE
      PRSHOR=(TRSHOR/TRCUFS)*100.
C
C     COMPUTE AVERAGE ANNUAL ACREAGE, CIR, CROP CONSUMPTIVE USE, SHORTAGE,
C     INCIDENTAL DEPLETION, CONSERVATION RESERVE DEPLETION AND TOTAL DEPLETION
C     FOR REGIONS
C
      AVTAC=AVTAC+TRACRE
      AVWCR=AVWCR+WRCIR
      AVCUFS=AVCUFS+TRCUFS
      AVSHOR=AVSHOR+TRSHOR
      AVPSOR=AVPSOR+PRSHOR
      AVCUWS=AVCUWS+TRCUWS
      AVDEP=AVDEP+TRDEPI
      AVCON=AVCON+TRDCON
      AVDIR=AVDIR+TRDIRR
      IF(J.LT.NUMYRS) GO TO 940
      AVTAC=AVTAC/REAL(NUMYRS)
      AVWCR=AVWCR/REAL(NUMYRS)
      AVCUFS=AVCUFS/REAL(NUMYRS)
      AVSHOR=AVSHOR/REAL(NUMYRS)
      AVPSOR=AVPSOR/REAL(NUMYRS)
      AVCUWS=AVCUWS/REAL(NUMYRS)
      AVDEP=AVDEP/REAL(NUMYRS)
      AVCON=AVCON/REAL(NUMYRS)
      AVDIR=AVDIR/REAL(NUMYRS)
C
C     PRINT CONSUMPTIVE USE ACCOUNTING RESULTS BY REGION
C
  940 IF(J.EQ.1) WRITE(11,950) TITLE,REGION(I)
  950 FORMAT(10X,'ANNUAL IRRIGATION CONSUMPTIVE USES'//1X,A80/1X,
     1  'REGION: ',A40//,18X,'CROP',7X,'CROP',77X,'TOTAL',/,16X,
     2  'WEIGHTED',4X,'CU FULL',4X,'SHORTAGE',2X,'SHORTAGE',2X,
     3  'CONSUMPTIVE',4X,'INCIDENTAL',6X,'CONSERVATION',7X,
     4  'IRRIGATION'/1X,'YEAR', 4X,'ACRES',2X,'CIR (FT)',2X,
     5  'SUPPLY (AF)',4X,'(AF)',6X,'(%)',6X,'USE (AF)',4X,
     6  'DEPLETIONS (AF)',3X,'DEPLETION (AF)',3X, 'DEPLETION (AF)'/1X,
     7  121('=')/)
      WRITE(11,880) NYR(J),TRACRE,WRCIR,TRCUFS,TRSHOR,PRSHOR,TRCUWS,
     1  TRDEPI,TRDCON,TRDIRR
      IF(J.LT.NUMYRS) GO TO 970
      WRITE(11,890) AVTAC,AVWCR,AVCUFS,AVSHOR,AVPSOR,AVCUWS,AVDEP,AVCON,
     1  AVDIR
      WRITE(11,955)
  955 FORMAT(/'NOTE:SHORTAGE BASED ON USER INPUT PERCENTAGES EXCLUDES'
     1  'SHORTAGES AFTER USER INPUT WATER SUPPLY CUTOFF DATES, SUCH AS'
     2  'FOR SHORTED ALFALFA AND PASTURE.')
      L=LL-MOD((14+NUMYRS),LL)
      IF(L.LE.0) GO TO 970
      DO 960 K=1,L
      WRITE(11,670)
  960 CONTINUE
  970 CONTINUE
  980 CONTINUE
      CLOSE(11)
  990 IF(IOUT(3).LE.0) GO TO 1200
C
C     PRINT MONTHLY IRRIGATION DEPLETION DEMANDS FOR EACH IRRIGATED
C     AREA FOR HYDROLOGIC MODELING PURPOSES
C
      DO 1190 I=1,NAREAS
      WRITE(12,1000) TITLE,ARNAME(I),(MON(K),K=1,12)
 1000 FORMAT(10X,'IRRIGATION DEPLETIONS IN ACRE-FEET'//1X,A80/1X,
     1  'IRRIGATED AREA: ',A40//1X,'YEAR',12(6X,A3)/1X,
     2  112('=')/)
      DO 1010 K=1,12
      DEPMO(K)=0.
 1010 CONTINUE
      DO 1080 J=1,NUMYRS
      DO 1020 K=1,12
      DEPMO(K)=DEPMO(K)+DEPIRR(I,J,K)
 1020 CONTINUE
      IF(J.LT.NUMYRS) GO TO 1040
      DO 1030 K=1,12
      DEPMO(K)=DEPMO(K)/REAL(NUMYRS)
 1030 CONTINUE
 1040 WRITE(12,1050) NYR(J),(DEPIRR(I,J,K),K=1,12)
 1050 FORMAT(1X,I4,12F9.0)
      IF(J.LT.NUMYRS) GO TO 1080
      WRITE(12,1060) (DEPMO(K),K=1,12)
 1060 FORMAT (/'AVERAGE',F7.0,11F9.0)
      WRITE(12,1065)
 1065 FORMAT(/' NOTE: DEPLETIONS EXCLUDE THOSE ASSOCIATED WITH WATERING'
     1  ' CONSERVATION RESERVE ACRES TO MAINTAIN GROUND COVER')
      L=LL-MOD((12+NUMYRS),LL)
      IF(L.LE.0) GO TO 1080
      DO 1070 K=1,L
      WRITE(12,670)
 1070 CONTINUE
 1080 CONTINUE
C
C     PRINT CROP ACRES
C
      WRITE(12,1090) TITLE,ARNAME(I)
 1090 FORMAT(10X,'IRRIGATED ACRES'//1X,A80/1X,'IRRIGATED AREA: ',A40)
      IC=0
      DO 1100 J=1,NUMYRS
      IF(MOD(J,12).EQ.1) IC=IC+1
 1100 CONTINUE
      DO 1180 K=1,IC
      J1=(K-1)*12+1
      IF(K.LT.IC) J2=J1+11
      IF(K.EQ.IC) J2=NUMYRS
      WRITE(12,1110) (NYR(J),J=J1,J2)
 1110 FORMAT(//10X,'CROP',13X,12(5X,I4)/1X,134('='))
      DO 1130 IM=1,NCROPS(I)
      WRITE(12,1120) CRTIT(ICROPS(I,IM)),(CACRE(I,J,IM),J=J1,J2)
 1120 FORMAT(1X,A24,12F9.0)
 1130 CONTINUE
      WRITE(12,1140) (TACRE(I,J),J=J1,J2)
 1140 FORMAT(/14X,'TOTAL ACRES',12F9.0)
      WRITE(12,1150) (DOUBC(I,J),J=J1,J2)
 1150 FORMAT(11X,'DOUBLE-CROPPED',12F9.0)
      IF(MOD(K,3).EQ.0) THEN
      L1=4+3*(7+NCROPS(I))
      L=LL-MOD(L1,LL)
      IF(L.LE.0) GO TO 1180
      DO 1160 M=1,L
      WRITE(12,670)
 1160 CONTINUE
      GO TO 1180
      ENDIF
      IF(K.LT.IC) GO TO 1180
      IF(K.LE.3) L1=4+K*(7+NCROPS(I))
      IF(K.GT.3) L1=MOD(K,3)*(7+NCROPS(I))
      L=LL-MOD(L1,LL)
      IF(L.LE.0) GO TO 1180
      DO 1170 M=1,L
      WRITE(12,670)
 1170 CONTINUE
 1180 CONTINUE
 1190 CONTINUE
      CLOSE(12)
C
C     END OF PROGRAM
C
 1200 WRITE(*,1210)
 1210 FORMAT(/' PROGRAM EXECUTION IS COMPLETE'/)
      STOP
      END
      SUBROUTINE CIRCAL(IAREA,JYEAR,ICALC,MFEP)
C
C     THIS SUBROUTINE COMPUTES CONSUMPTIVE IRRIGATION REQUIREMENTS USING EITHER
C     THE ORIGINAL BLANEY-CRIDDLE METHOD (1950, 1962) OR THE SCS MODIFIED
C     BLANEY-CRIDDLE METHOD (1970), WITH USBR OR SCS EFFECTIVE RAINFALL, AS
C     SPECIFIED BY THE USER.
C
C     DATA DEFINITIONS FOR VARIABLES NOT DEFINED IN MAIN PROGRAM
C
C     AC    =IRRIGATED ACREAGE FOR A CROP
C     ACIR  =ARRAY OF ANNUAL CIR'S FOR EACH CROP
C     B     =JULIAN DAY MARKING THE BEGINNING OF THE GROWING SEASON
C     BD    =JULIAN DAY MARKING PLANTING OR FIRST IRRIGATION DATE
C     CDR   =CROP DISTRIBUTION RATIO
C     CIRFT =ANNUAL CONSUMPTIVE IRRIGATION REQUIREMENT FOR A CROP IN FEET
C     CIR   =CONSUMPTIVE IRRIGATION REQUIREMENT FOR A MONTH
C     CT    =CROP TYPE (ANNUAL(AN),BIANNUAL(BI),PERENNIAL(PR),WINTER GRAIN(WG))
C     DAP   =DAYS AFTER PLANTING (OR AFTER GROWTH RESUMES IN SPRING FOR WG)
C     DAPTM =DAYS AFTER PLANTING TO MIDPOINT OF GROWING DAYS IN MONTH
C     DAYB  =ARRAY OF JULIAN DAYS ASSOCIATED WITH THE BEGINNING OF EACH MONTH
C     DAYMP =ARRAY OF JULIAN DAYS ASSOCIATED WITH THE MIDPOINT OF EACH MONTH
C     DAYE  =ARRAY OF JULIAN DAYS ASSOCIATED WITH THE END OF EACH MONTH
C     DIFF  =NUMBER OF GROWING DAYS INSIDE FROST-FREE PERIOD DURING A MONTH
C     DOFF  =NUMBER OF GROWING DAYS OUTSIDE FROST-FREE PERIOD DURING A MONTH
C     E     =JULIAN DAY MARKING THE END OF THE GROWING SEASON
C     ED    =JULIAN DAY MARKING HARVEST OR WATER SUPPLY CUTOFF DATE
C     F     =MONTHLY CONSUMPTIVE USE FACTOR
C     FDAYS =DAYS BETWEEN PLANTING AND END OF GROWTH IN FALL FOR WINTER GRAIN
C     FM28  =FIRST JULIAN DAY IN FALL OF MINIMUM 28 DEGREES
C     FM32  =FIRST JULIAN DAY IN FALL OF MINIMUM 32 DEGREES
C     GD    =NUMBER OF DAYS WHEN ET OCCURRED, EXCLUDES DAYS WHEN CROP IS DORMANT
C     GS    =NUMBER OF DAYS IN GROWING SEASON
C     IAREA =INDEX NUMBER FOR IRRIGATED AREA
C     ICALC =CONTROL FLAG FOR CIR CALCULATION METHOD
C     JYEAR =COMPUTATION YEAR
C     KC    =CONSUMPTIVE USE COEFFICIENT FOR SCS MODIFIED BLANEY-CRIDDLE METHOD
C     KT    =CORRECTION FACTOR FOR CU COEFFICIENTS USED WITH MODIFIED B-C METHOD
C     MDB   =FIRST DAY OF GROWTH WITHIN THE BEGINNING MONTH FOR A CROP
C     MDE   =LAST DAY OF GROWTH WITHIN THE LAST MONTH FOR A CROP
C     MOB   =BEGINNING MONTH FOR GROWTH SEASON FOR A CROP
C     MOE   =LAST MONTH FOR GROWTH SEASON FOR A CROP
C     MGS   =NUMBER OF DAYS IN THE GROWING SEASON FOR A CROP
C     MGSF  =NUMBER OF DAYS OF GROWTH IN THE FALL FOR A FALL-PLANT CROP (WG)
C     MGSS  =NUMBER OF DAYS OF GROWTH IN THE SPRING FOR A FALL-PLANT CROP (WG)
C     NC    =CROP IDENTIFICATION NUMBER
C     NGD   =NUMBER OF DAYS WHEN ET OCCURRED BY A CROP IN A MONTH
C     NGDT  =NUMBER OF DAYS WHEN ET OCCURRED BY A CROP FOR A YEAR
C     PDH   =PERCENTAGE OF DAYLIGHT HOURS DURING THE GROWING DAYS IN A MONTH
C     SM28  =LAST JULIAN DAY IN SPRING OF MINIMUM 28 DEGREES
C     SM32  =LAST JULIAN DAY IN SPRING OF MINIMUM 32 DEGREES
C     RE    =EFFECTIVE PRECIPITATION IN INCHES FOR AN IRRIGATED AREA
C     SDAYS =DAYS BETWEEN BEGINNING OF GROWTH IN SPRING AND HARVEST FOR W. GRAIN
C     STG   =STAGE OF GROWTH OF CROP
C     TCIR  =ANNUAL CONSUMPTIVE IRRIGATION REQUIREMENT FOR A CROP IN INCHES
C     TCIR2 =WEIGHTED ANNUAL CONSUMPTIVE IRRIGATION REQUIREMENT FOR AN AREA
C     TAGD  =AVERAGE TEMPERATURE FOR GROWING DAYS IN THE MONTH
C     TR    =ANNUAL PRECIPITATION IN INCHES FOR AN IRRIGATED AREA
C     TRE   =ANNUAL EFFECTIVE PRECIPITATION IN INCHES FOR AN IRRIGATED AREA 
C     TU    =ANNUAL CONSUMPTIVE USE (EVAPOTRANSPIRATION) IN INCHES
C     U     =MONTHLY CONSUMPTIVE USE (EVAPOTRANSPIRATION) IN INCHES
C     UI    =MONTHLY CONSUMPTIVE USE INSIDE FROST-FREE PERIOD
C     UO    =MONTHLY CONSUMPTIVE USE OUTSIDE FROST-FREE PERIOD
C     WCIR  =ARRAY OF WEIGHTED ANNUAL CIR'S FOR EACH CROP
C     WCIRMO=ARRAY OF WEIGHTED CIR'S BY MONTH
C     WGH   =HARVEST DATE FOR WINTER GRAIN
C     WGP   =PLANTING DATE FOR WINTER GRAIN
C
C     DATA DECLARATIONS
C
      REAL CACRE(50,100,30),TACRE(50,100),DOUBC(50,100),CMIX(50,100,30),
     1  APPDEP(50,100),TEM(30),TLM(30),CIFF(30),COFF(30),GSL(30),
     2  C(30,2,25),PRECA(50,100,12),DAYS(12),TEMPA(50,100,12),PD(50,12),
     3  T(12),P(12),ACIR(30),WCIR(30),CIROBC(30,12),CIRMBC(30,12),
     4  TCIRO(30),TCIRM(30),REBC(2,12),UBC(2,12),DAYB(12),DAYMP(12),
     5  DAYE(12),TB12(50),TA1(50),KC,KT,WCIRMO(12)
      INTEGER NYR(100),NCROPS(50),NPSTA(50),NTSTA(50),ICROPS(50,100),
     1  IREG(50),IOUT(4),MSM28(2,50,100),MSM32(2,50,100),
     2  MFM32(2,50,100),MFM28(2,50,100),MBEGM(50,30,100),
     3  MBEGD(50,30,100),MENDM(50,30,100),MENDD(50,30,100)
      DIMENSION ARNAME(50),CRTIT(30),WSTIT(25),CTYPE(30),MON(13),
     1  REGION(20)
      CHARACTER TITLE*80,MON*3,ARNAME*40,CRTIT*24,EP*4,WSTIT*40,
     1  REGION*40,CTYPE*2,CT*2
      COMMON/BLKCIR/ CACRE,TACRE,DOUBC,CMIX,APPDEP,GSL,TEM,TLM,C,CIFF,
     1  COFF,PRECA,TEMPA,TB12,TA1,PD,CIROBC,CIRMBC,TCIRO,TCIRM,REBC,UBC,
     2  NYR,NCROPS,NPSTA,NTSTA,ICROPS,NALF,NALFS,IREG,IOUT,MSM28,MSM32,
     3  MFM32,MFM28,MBEGM,MBEGD,MENDM,MENDD,NUMYRS,TITLE,MON,ARNAME,
     4  CRTIT,WSTIT,CTYPE,REGION,LP,LL
      COMMON/BLKDAY/ DAYS
C
C     ASSIGN DAY VALUES FOR EACH MONTH
C
      DAYS(2)=28.
      IF(MOD(NYR(JYEAR),4).EQ.0) DAYS(2)=29.
      DAYB(1)=1.
      DAYMP(1)=16.
      DAYE(1)=31.
      DO 10 K=2,12
      DAYB(K)=DAYB(K-1)+DAYS(K-1)
      DAYE(K)=DAYE(K-1)+DAYS(K)
      DMP=(DAYE(K-1)+DAYE(K))/2.
      MDMP=INT(DMP+0.5)
      DAYMP(K)=REAL(MDMP)
   10 CONTINUE
C
C     ASSIGN MONTHLY AVERAGE TEMPERATURES AND PRECIPITATION
C
      DO 20 K=1,12
      T(K)=TEMPA(IAREA,JYEAR,K)
      P(K)=PRECA(IAREA,JYEAR,K)
   20 CONTINUE
C
C     CONVERT FROST DATES TO JULIAN DAYS
C
      SM28=0.
      SM32=0.
      FM32=0.
      FM28=0.
      IF(MSM28(1,IAREA,JYEAR).GT.0) CALL DATES(SM28,
     1  MSM28(1,IAREA,JYEAR),MSM28(2,IAREA,JYEAR),NYR(JYEAR),1)
      IF(MSM32(1,IAREA,JYEAR).GT.0) CALL DATES(SM32,
     1  MSM32(1,IAREA,JYEAR),MSM32(2,IAREA,JYEAR),NYR(JYEAR),1)
      IF(MFM32(1,IAREA,JYEAR).GT.0) CALL DATES(FM32,
     1  MFM32(1,IAREA,JYEAR),MFM32(2,IAREA,JYEAR),NYR(JYEAR),1)
      IF(MFM28(1,IAREA,JYEAR).GT.0) CALL DATES(FM28,
     1  MFM28(1,IAREA,JYEAR),MFM28(2,IAREA,JYEAR),NYR(JYEAR),1)
C
C     INITIALIZE IRRIGATED AREA CIR SUMMATION VARIABLES
C
      TAC=TACRE(IAREA,JYEAR)+DOUBC(IAREA,JYEAR)
      TAC2=0.0
      TCDR=0.0
      TCIR2=0.0
      TWCIR=0.0
      DO 25 K=1,12
      WCIRMO(K)=0.0
   25 CONTINUE
C
C     PRINT IRRIGATED AREA HEADING INFORMATION FOR CROP CIR DETAIL OUTPUT
C
      IF(IOUT(1).LE.0) GO TO 60
      IF(MFEP.LE.0) EP='  NO'
      IF(MFEP.EQ.1) EP='USBR'
      IF(MFEP.GE.2) EP=' SCS'
      IF(ICALC.EQ.1) WRITE(10,30) EP
   30 FORMAT(10X,'THE ORIGINAL BLANEY-CRIDDLE METHOD'/5X,
     1  '(EFFECTIVE RAINFALL BASED ON THE ',A4,' METHOD)'/)
      IF(ICALC.EQ.2) WRITE(10,40) EP
   40 FORMAT(7X,'THE SCS MODIFIED BLANEY-CRIDDLE METHOD'/5X,
     1  '(EFFECTIVE RAINFALL BASED ON THE ',A4,' METHOD)'/)
      IF((MSM28(1,IAREA,JYEAR)).EQ.0.) THEN
      MSM28(1,IAREA,JYEAR)=13.
      ENDIF
      IF((MSM32(1,IAREA,JYEAR)).EQ.0.) THEN
      MSM32(1,IAREA,JYEAR)=13.
      ENDIF
      IF((MFM32(1,IAREA,JYEAR)).EQ.0.) THEN
      MFM32(1,IAREA,JYEAR)=13.
      ENDIF
      IF((MFM28(1,IAREA,JYEAR)).EQ.0.) THEN
      MFM28(1,IAREA,JYEAR)=13.
      ENDIF
      WRITE(10,50) TITLE,ARNAME(IAREA),NYR(JYEAR),WSTIT(NPSTA(IAREA)),
     1  WSTIT(NTSTA(IAREA)),MON(MSM28(1,IAREA,JYEAR)),
     2  MSM28(2,IAREA,JYEAR),MON(MSM32(1,IAREA,JYEAR)),
     3  MSM32(2,IAREA,JYEAR),MON(MFM32(1,IAREA,JYEAR)),
     4  MFM32(2,IAREA,JYEAR),MON(MFM28(1,IAREA,JYEAR)),
     5  MFM28(2,IAREA,JYEAR)
      IF((MSM28(1,IAREA,JYEAR)).EQ.13.) THEN
      MSM28(1,IAREA,JYEAR)=0.
      ENDIF
      IF((MSM32(1,IAREA,JYEAR)).EQ.13.) THEN
      MSM32(1,IAREA,JYEAR)=0.
      ENDIF
      IF((MFM32(1,IAREA,JYEAR)).EQ.13.) THEN
      MFM32(1,IAREA,JYEAR)=0.
      ENDIF
      IF((MFM28(1,IAREA,JYEAR)).EQ.13.) THEN
      MFM28(1,IAREA,JYEAR)=0.
      ENDIF
   50 FORMAT(1X,A80/4X,'IRRIGATED AREA: ',A40/4X,'YEAR: ',I4/4X,
     1  'PRECIP STATION: ',A40/4X,'TEMP STATION: ',A40//4X,
     2  'DATE OF LAST SPRING MINIMUM OF 28 DEGREES OR BELOW: ',A3,I3/4X,
     3  'DATE OF LAST SPRING MINIMUM OF 32 DEGREES OR BELOW: ',A3,I3/4X,
     4  'DATE OF FIRST FALL MINIMUM OF 32 DEGREES OR BELOW: ',A3,I3/4X,
     5  'DATE OF FIRST FALL MINIMUM OF 28 DEGREES OR BELOW: ',A3,I3)
      LCTR=13
C
C     COMPUTE ANNUAL CIR FOR EACH CROP
C
   60 DO 460 IM=1,NCROPS(IAREA)
      NC=ICROPS(IAREA,IM)
      CT=CTYPE(NC)
      AC=CACRE(IAREA,JYEAR,IM)
      CDR=CMIX(IAREA,JYEAR,IM)
C
C     COMPUTE JULIAN DAY FOR EARLIEST THEORETICAL MOISTURE USE (USE LAST SPRING
C     MINIMUM FROST DATE OR MEAN MONTHLY TEMPERATURES AS SPECIFIED FOR CROP)
C
      IF(TEM(NC).EQ.28.) THEN
      B=SM28
      GO TO 110
      ENDIF
      IF(TEM(NC).EQ.32.) THEN
      B=SM32
      GO TO 110
      ENDIF
      DO 100 K=1,12
      IF(T(K).LT.TEM(NC)) GO TO 100
      IF(T(K).EQ.TEM(NC)) THEN
      B=DAYMP(K)
      GO TO 110
      ENDIF
      IF(JYEAR.LE.1) GO TO 90
      IF(K.LE.1) GO TO 80
   70 B=DAYMP(K-1)+(DAYMP(K)-DAYMP(K-1))*(TEM(NC)-T(K-1))/(T(K)-T(K-1))
      GO TO 110
   80 IF(TEMPA(IAREA,JYEAR-1,12).LE.TEM(NC)) THEN
      B=-15.+31.*(TEM(NC)-TEMPA(IAREA,JYEAR-1,12))/(T(1)-
     1  TEMPA(IAREA,JYEAR-1,12))
      IF(B.LT.1.) B=1.
      GO TO 110
      ENDIF
      B=1.
      GO TO 110
   90 IF(K.GT.1) GO TO 70
      IF(TB12(IAREA).GE.TEM(NC)) B=1.
      IF(TB12(IAREA).LT.TEM(NC)) THEN
      B=-15.+31.*(TEM(NC)-TB12(IAREA))/(T(1)-TB12(IAREA))
      IF(B.LT.1.) B=1.
      ENDIF
      GO TO 110
  100 CONTINUE
C
C     COMPUTE JULIAN DAY FOR LATEST THEORETICAL MOISTURE USE (USE FIRST FALL
C     MINIMUM FROST DATE OR MEAN MONTHLY TEMPERATURES AS SPECIFIED FOR CROP)
C
  110 IF(TLM(NC).EQ.32.) THEN
      E=FM32
      GO TO 170
      ENDIF
      IF(TLM(NC).EQ.28.) THEN
      E=FM28
      GO TO 170
      ENDIF
      DO 120 K=1,12
      IF(DAYMP(K).LT.B) GO TO 120
      IF(K.LT.12) MO=K+1
      IF(K.EQ.12) MO=K
      IF(MO.LT.7)MO=7
      GO TO 130
  120 CONTINUE
  130 DO 160 K=MO,12
      IF(T(K).GT.TLM(NC)) GO TO 140
      IF(T(K).EQ.TLM(NC)) THEN
      E=DAYMP(K)
      GO TO 170
      ENDIF
      E=DAYMP(K-1)+(DAYMP(K)-DAYMP(K-1))*(TLM(NC)-T(K-1))/(T(K)-T(K-1))
      GO TO 170
  140 IF(K.LT.12) GO TO 160
      IF(JYEAR.GE.NUMYRS) GO TO 150
      IF(TEMPA(IAREA,JYEAR+1,1).LE.TLM(NC)) THEN
      E=DAYMP(12)+31.*(TLM(NC)-T(12))/(TEMPA(IAREA,JYEAR+1,1)-T(12))
      IF(E.GT.DAYE(12)) E=DAYE(12)
      GO TO 170
      ENDIF
      E=DAYE(12)
      GO TO 170
  150 IF(TA1(IAREA).GE.TLM(NC)) E=DAYE(12)
      IF(TA1(IAREA).LT.TLM(NC)) THEN
      E=DAYMP(12)+31.*(TLM(NC)-T(12))/(TA1(IAREA)-T(12))
      IF(E.GT.DAYE(12)) E=DAYE(12)
      GO TO 170
      ENDIF
  160 CONTINUE
C
C     ADJUST DAY NUMBERS MARKING THE BEGINNING AND END OF THE GROWING SEASON TO
C     REFLECT PLANTING OR FIRST IRRIGATION DATES AND HARVEST OR WATER SUPPLY
C     CUTOFF DATES FOR PERENNIAL AND ANNUAL CROPS
C
  170 IF(CT.EQ.'WG') GO TO 190
      BD=0.
      ED=0.
      IF(MBEGM(IAREA,NC,JYEAR).GT.0) CALL DATES(BD,
     1  MBEGM(IAREA,NC,JYEAR),MBEGD(IAREA,NC,JYEAR),NYR(JYEAR),1)
      IF(MENDM(IAREA,NC,JYEAR).GT.0) CALL DATES(ED,
     1  MENDM(IAREA,NC,JYEAR),MENDD(IAREA,NC,JYEAR),NYR(JYEAR),1)
      IF((BD.GT.0.).AND.(B.LT.BD)) B=BD
      IF((ED.GT.0.).AND.(E.GT.ED)) E=ED
      IF(E.LT.B) E=B
C
C     ADJUST THE DAY NUMBER MARKING THE END OF THE GROWING SEASON TO REFLECT THE
C     MAXIMUM GROWING SEASON LENGTH FOR AN ANNUAL OR PERENNIAL CROP
C
      MB=INT(B+0.5)
      B=REAL(MB)
      ME=INT(E+0.5)
      E=REAL(ME)
      GS=E-B+1.
      IF(GSL(ICROPS(IAREA,IM)).LE.0.) GO TO 180
      IF(GS.GT.GSL(ICROPS(IAREA,IM))) THEN
      E=B+GSL(ICROPS(IAREA,IM))-1.
      ME=INT(E+0.5)
      E=REAL(ME)
      GS=E-B+1.
      ENDIF
C
C     COMPUTE GROWTH SEASON LENGTH AND BEGINNING AND END DATES
C
  180 MGS=INT(GS)
      CALL DATES(B,MOB,MDB,NYR(JYEAR),2)
      CALL DATES(E,MOE,MDE,NYR(JYEAR),2)
      GO TO 200
C
C     SET THE SPRING HARVEST DATE AND THE SUMMER PLANTING DATE FOR WINTER GRAIN
C
  190 WGH=DAYE(8)
      WGP=DAYB(9)
      IF(MENDM(IAREA,NC,JYEAR).GT.0) CALL DATES(WGH,
     1  MENDM(IAREA,NC,JYEAR),MENDD(IAREA,NC,JYEAR),NYR(JYEAR),1)
      IF(MBEGM(IAREA,NC,JYEAR).GT.0) CALL DATES(WGP,
     1  MBEGM(IAREA,NC,JYEAR),MBEGD(IAREA,NC,JYEAR),NYR(JYEAR),1)
C
C     DETERMINE THE SPRING AND FALL GROWING SEASONS FOR WINTER GRAIN
C
      MB=INT(B+0.5)
      B=REAL(MB)
      ME=INT(E+0.5)
      E=REAL(ME)
      IF(B.GT.WGH) B=WGH
      IF(E.LT.WGP) E=WGP
      SDAYS=WGH-B+1.
      FDAYS=E-WGP+1.
C
C     COMPUTE SPRING AND FALL GROWTH SEASON DATES FOR WINTER GRAIN
C
      MGSS=INT(SDAYS)
      MGSF=INT(FDAYS)
      CALL DATES(B,MOB,MDB,NYR(JYEAR),2)
      CALL DATES(WGH,MOH,MDH,NYR(JYEAR),2)
      CALL DATES(WGP,MOP,MDP,NYR(JYEAR),2)
      CALL DATES(E,MOE,MDE,NYR(JYEAR),2)
C
C     INITIALIZE ANNUAL CROP CIR SUMMATION VARIABLES AND CIR COMPUTATION FLAGS
C
  200 CIR=0.
      NGDT=0
      DAP=0.
      TR=0.
      TU=0.
      TRE=0.
      TCIR=0.
C
C     COMPUTE MONTHLY CIR FOR A CROP
C
      DO 410 K=1,12
C
C     PRINT HEADINGS FOR TABLES OF MONTHLY CIR FOR A CROP
C
      IF((IOUT(1).LE.0).OR.(K.GT.1)) GO TO 260
      LCTR=LCTR+8
      IF(ICALC.GE.2) GO TO 230
      IF(CT.NE.'WG') WRITE(10,210) IM,CRTIT(NC),MON(MOB),MDB,MON(MOE),
     1  MDE,MGS
  210 FORMAT(///4X,'TABLE ',I2,'. MONTHLY CIR FOR: ',A24/4X,'GROWING ',
     1  'SEASON: ',A3,I3,' TO ',A3,I3,', LENGTH ',I3,' DAYS'/4X,64('=')/
     2  4X,'MONTH',1X,'DAYS',1X,'TEMP',2X,'RAIN',1X,'LIGHT',5X,'F',1X,
     3  'KIFF',1X,'KOFF',3X,'ETc',4X,'Re',3X,'CIR'/4X,64('='))
      IF(CT.EQ.'WG') WRITE(10,220) IM,CRTIT(NC),MON(MOB),MDB,MON(MOH),
     1  MDH,MGSS,MON(MOP),MDP,MON(MOE),MDE,MGSF
  220 FORMAT(//4X,'TABLE ',I2,'. MONTHLY CIR FOR: ',A24/4X,'GROWING ',
     1  'SEASON: SPRING, ',A3,I3,' TO ',A3,I3,', LENGTH ',I3,' DAYS',
     2  /24X, 'FALL,   ',A3,I3,' TO ',A3,I3,', LENGTH ',I3,' DAYS'/4X,
     3  64('=')/4X,'MONTH',1X,'DAYS',1X,'TEMP',2X,'RAIN',1X,'LIGHT',5X,
     4  'F',1X,'KIFF',1X,'KOFF',3X,'ETc',4X,'Re',3X,'CIR'/4X,64('='))
      GO TO 260
  230 IF(CT.NE.'WG') WRITE(10,240) IM,CRTIT(NC),MON(MOB),MDB,MON(MOE),
     1  MDE,MGS
  240 FORMAT(///4X,'TABLE ',I2,'. MONTHLY CIR FOR: ',A24/4X,'GROWING ',
     1  'SEASON: ',A3,I3,' TO ',A3,I3,', LENGTH ',I3,' DAYS'/4X,64('=')/
     2  4X,'MONTH',1X,'DAYS',1X,'TEMP',2X,'RAIN',1X,'LIGHT',5X,'F',3X,
     3  'Kc',3X,'Kt',3X,'ETc',4X,'Re',3X,'CIR'/4X,64('='))
      IF(CT.EQ.'WG') WRITE(10,250) IM,CRTIT(NC),MON(MOB),MDB,MON(MOH),
     1  MDH,MGSS,MON(MOP),MDP,MON(MOE),MDE,MGSF
  250 FORMAT(//4X,'TABLE ',I2,'. MONTHLY CIR FOR: ',A24/4X,'GROWING ',
     1  'SEASON: SPRING, ',A3,I3,' TO ',A3,I3,', LENGTH ',I3,' DAYS',
     2  /24X,'FALL,   ',A3,I3,' TO ',A3,I3,', LENGTH ',I3,' DAYS'/4X,
     3  64('=')/ 4X,'MONTH',1X,'DAYS',1X,'TEMP',2X,'RAIN',1X,'LIGHT',5X,
     4  'F',3X,'Kc',3X,'Kt',3X,'ETc',4X,'Re',3X,'CIR'/4X,64('='))
C
C     COMPUTE NUMBER OF GROWING DAYS IN THE MONTH FOR PERENNIAL OR ANNUAL CROP,
C     AND THE JULIAN DAY FOR THE MIDPOINT OF THE GROWING DAYS IN THE MONTH
C
  260 IF(CT.EQ.'WG') GO TO 270
      IF(B.GT.DAYE(K)) GO TO 410
      IF(E.LT.DAYB(K)) GO TO 410
      IF(MOE.EQ.MOB) THEN
      GD=E-B+1.
      GDMP=(E+B)/2.
      GO TO 290
      ENDIF
      IF(B.GE.DAYB(K)) THEN
      GD=DAYE(K)-B+1.
      GDMP=(DAYE(K)+B)/2.
      GO TO 290
      ENDIF
      IF((B.LT.DAYB(K)).AND.(E.GE.DAYE(K))) THEN
      GD=DAYS(K)
      GDMP=DAYMP(K)
      GO TO 290
      ENDIF
      IF(E.GE.DAYB(K)) THEN
      GD=E-DAYB(K)+1.
      GDMP=(DAYB(K)+E)/2.
      ENDIF
      GO TO 290
C
C     COMPUTE NUMBER OF GROWING DAYS IN THE MONTH FOR CROP PLANTED IN THE FALL
C     AND HARVESTED IN THE SPRING (WINTER GRAIN)
C
  270 GD=0.
      IF(K.GT.8) GO TO 280
      IF(B.GT.DAYE(K)) GO TO 410
      IF(WGH.LT.DAYB(K)) GO TO 405
      IF(MOH.EQ.MOB) THEN
      GD=WGH-B+1.
      GDMP=(WGH+B)/2.
      GO TO 290
      ENDIF
      IF(B.GE.DAYB(K)) THEN
      GD=DAYE(K)-B+1.
      GDMP=(DAYE(K)+B)/2.
      GO TO 290
      ENDIF
      IF((B.LT.DAYB(K)).AND.(WGH.GE.DAYE(K))) THEN
      GD=DAYS(K)
      GDMP=DAYMP(K)
      GO TO 290
      ENDIF
      IF(WGH.GE.DAYB(K)) THEN
      GD=WGH-DAYB(K)+1.
      GDMP=(DAYB(K)+WGH)/2.
      ENDIF
      GO TO 290
  280 IF(WGP.GE.DAYE(K)) GO TO 410
      IF(E.LT.DAYB(K)) GO TO 410
      IF(MOE.EQ.MOP) THEN
      GD=E-WGP+1.
      GDMP=(E+WGP)/2.
      GO TO 290
      ENDIF
      IF(WGP.GE.DAYB(K)) THEN
      GD=DAYE(K)-WGP+1.
      GDMP=(DAYE(K)+WGP)/2.
      GO TO 290
      ENDIF
      IF((WGP.LT.DAYB(K)).AND.(E.GE.DAYE(K))) THEN
      GD=DAYS(K)
      GDMP=DAYMP(K)
      GO TO 290
      ENDIF
      IF(E.GE.DAYB(K)) THEN
      GD=E-DAYB(K)+1.
      GDMP=(DAYB(K)+E)/2.
      ENDIF
C
C     DETERMINE DAYS AFTER START OF GROWTH SEASON
C
  290 NGD=INT(GD)
      NGDT=NGDT+NGD
      DAP=DAP+GD
      DAPTM=DAP-(GD/2.)
C
C     DETERMINE DAYLIGHT HOURS PERCENTAGE AND AVERAGE TEMPERATURE FOR GROWING
C     DAYS IN MONTH, AND COMPUTE CONSUMPTIVE USE FACTOR
C
      PDH=PD(IAREA,K)*GD/DAYS(K)
      IF(GDMP.GT.DAYMP(K)) GO TO 300
      IF(GDMP.EQ.DAYMP(K)) THEN
      TAGD=T(K)
      GO TO 310
      ENDIF
      TAGD=T(K-1)+(T(K)-T(K-1))*(GDMP-DAYMP(K-1))/(DAYMP(K)-DAYMP(K-1))
      GO TO 310
  300 TAGD=T(K)+(T(K+1)-T(K))*(GDMP-DAYMP(K))/(DAYMP(K+1)-DAYMP(K))
  310 F=(TAGD*PDH)/100.0
      IF(ICALC.GE.2) GO TO 340
C
C     DETERMINE THE NUMBER OF GROWING DAYS INSIDE AND OUTSIDE THE FROST-FREE
C     PERIOD FOR THE ORIGINAL BLANEY-CRIDDLE METHOD
C
      IF(CT.EQ.'WG') GO TO 330
      IF(SM32.EQ.0.) THEN
      DOFF=0.
      DIFF=GD
      GO TO 320
      ENDIF
C
C     MID SEASON CONDITIONS
C
      IF((B.LT.DAYB(K)).AND.(SM32.LT.DAYB(K)).AND.(FM32.GT.DAYE(K)).AND.
     1  (E.GT.DAYE(K))) THEN
      DOFF=0.
      DIFF=GD
      GO TO 320
      ENDIF
C
C     SPRING CONDITIONS OR BEGINNING OF GROWING SEASON
C
      IF((B.LT.DAYB(K)).AND.(SM32.GE.DAYE(K))) THEN
      DOFF=GD
      DIFF=0.
      GO TO 320
      ENDIF
      IF((B.LT.DAYB(K)).AND.(SM32.GE.DAYB(K)).AND.(SM32.LE.DAYE(K)))
     1  THEN
      DOFF=SM32-DAYB(K)+1.
      DIFF=GD-DOFF
      GO TO 320
      ENDIF
      IF((B.GE.DAYB(K)).AND.(B.LE.DAYE(K)).AND.(SM32.GE.DAYE(K))) THEN
      DOFF=GD
      DIFF=0.
      GO TO 320
      ENDIF
      IF((B.GE.DAYB(K)).AND.(B.LE.DAYE(K)).AND.(B.LT.SM32).AND.
     1  (SM32.LT.DAYE(K))) THEN
      DOFF=SM32-B+1.
      DIFF=GD-DOFF
      GO TO 320
      ENDIF
      IF((B.GE.DAYB(K)).AND.(B.LE.DAYE(K)).AND.(B.GE.SM32)) THEN
      DOFF=0.
      DIFF=GD
      GO TO 320
      ENDIF
C
C     FALL CONDITIONS OR END OF GROWING SEASON
C
      IF((FM32.LT.DAYB(K)).AND.(E.GE.DAYE(K))) THEN
      DOFF=GD
      DIFF=0.
      GO TO 320
      ENDIF
      IF((FM32.GE.DAYB(K)).AND.(FM32.LE.DAYE(K)).AND.(E.GE.DAYE(K)))
     1  THEN
      DOFF=DAYE(K)-FM32+1.
      DIFF=GD-DOFF
      GO TO 320
      ENDIF
      IF((FM32.LT.DAYB(K)).AND.(E.GE.DAYB(K)).AND.(E.LE.DAYE(K))) THEN
      DOFF=GD
      DIFF=0.
      GO TO 320
      ENDIF
      IF((FM32.GE.DAYB(K)).AND.(FM32.LE.E).AND.(E.GT.DAYB(K)).AND.
     1  (E.LE.DAYE(K))) THEN
      DOFF=E-FM32+1.
      DIFF=GD-DOFF
      GO TO 320
      ENDIF
      IF((E.GE.DAYB(K)).AND.(E.LE.DAYE(K)).AND.(E.LE.FM32)) THEN
      DOFF=0.
      DIFF=GD
      ENDIF
C
C     COMPUTE CROP CONSUMPTIVE USE FOR ANNUAL AND PERENNIAL CROPS USING THE
C     ORIGINAL BLANEY-CRIDDLE METHOD
C
  320 UO=F*DOFF/GD*COFF(NC)
      UI=F*DIFF/GD*CIFF(NC)
      U=UO+UI
      GO TO 370
C
C     COMPUTE CROP CONSUMPTIVE USE FOR WINTER WHEAT USING THE ORIGINAL BLANEY-
C     CRIDDLE METHOD AND FALL AND SPRING CROP COEFFICIENTS
C
  330 IF(K.LE.8) THEN
      DOFF=0.
      DIFF=GD
      U=F*CIFF(NC)
      ENDIF
      IF(K.GE.9) THEN
      DOFF=GD
      DIFF=0.
      U=F*COFF(NC)
      ENDIF
      GO TO 370
C
C     DETERMINE THE VALUE OF Kc FOR THE SCS MODIFIED BLANEY-CRIDDLE METHOD AT
C     THE MIDPOINT OF THE GROWING DAYS IN THE MONTH BASED ON THE GROWTH CURVE
C     FOR THE CROP (EXPRESSED AS A FUNCTION OF CALENDAR DATE FOR PERENNIAL CROPS
C     AND OF THE NUMBER OF DAYS IN THE GROWING SEASON FOR ANNUAL AND BIANNUAL
C     CROPS AND WINTER WHEAT)
C
  340 IF((CT.EQ.'AN').OR.(CT.EQ.'BI')) STG=DAPTM*100/GS
      IF(CT.EQ.'PR') STG=GDMP
      IF((CT.EQ.'WG').AND.(K.LE.8)) STG=DAPTM*100/SDAYS
      IF((CT.EQ.'WG').AND.(K.GE.9))THEN
      STG=DAPTM*100/FDAYS
      NC=NC+1
      ENDIF
      DO 350 J=1,25
      IF(STG.GT.C(NC,1,J)) GO TO 350
      IF(STG.EQ.C(NC,1,J)) THEN
      KC=C(NC,2,J)
      GO TO 360
      ENDIF
      KC=C(NC,2,J-1)+(C(NC,2,J)-C(NC,2,J-1))*(STG-C(NC,1,J-1))/
     1  (C(NC,1,J)-C(NC,1,J-1))
      GO TO 360
  350 CONTINUE
C
C     COMPUTE CROP CONSUMPTIVE USE USING THE SCS MODIFIED BLANEY-CRIDDLE METHOD
C
  360 KT=(0.0173*TAGD)-0.314
      IF(KT.LT.0.3) KT=0.3
      U=F*KT*KC
C
C     COMPUTE MONTHLY EFFECTIVE PRECIPITATION USING THE USBR METHOD
C
  370 IF(MFEP.EQ.1) THEN
      IF(P(K).LE.1.0) RE=0.95*P(K)
      IF((P(K).GT.1.0).AND.(P(K).LE.2.0)) RE=0.90*(P(K)-1.0)+0.95
      IF((P(K).GT.2.0).AND.(P(K).LE.3.0)) RE=0.82*(P(K)-2.0)+1.85
      IF((P(K).GT.3.0).AND.(P(K).LE.4.0)) RE=0.65*(P(K)-3.0)+2.67
      IF((P(K).GT.4.0).AND.(P(K).LE.5.0)) RE=0.45*(P(K)-4.0)+3.32
      IF((P(K).GT.5.0).AND.(P(K).LE.6.0)) RE=0.25*(P(K)-5.0)+3.77
      IF(P(K).GT.6.0) RE=0.05*(P(K)-6.0)+4.02
      ENDIF
C
C     COMPUTE MONTHLY EFFECTIVE PRECIPITATION USING THE SCS METHOD
C
      IF(MFEP.GE.2) THEN
      AD=APPDEP(IAREA,JYEAR)
      CRF=0.531747+(0.295164*AD)-(0.057697*AD**2)+(0.003804*AD**3)
      RE=(((0.70917*P(K)**0.82416)-0.11556)*10**(0.02426*U))*CRF
      IF(RE.LT.0.) RE=0.
      IF(RE.GT.P(K)) RE=P(K)
      ENDIF
C
C     COMPUTE MONTHLY CIR (WITH MONTHLY EFFECTIVE PRECIP PRORATED TO THE NUMBER
C     OF GROWING DAYS WITHIN THE MONTH)
C
      IF(MFEP.LE.0) RE=0.
      RE=RE*GD/DAYS(K)
      IF(NC.EQ.NALF) THEN
      REBC(1,K)=RE
      UBC(1,K)=U
      ENDIF
      IF(NC.EQ.NALFS) THEN
      REBC(2,K)=RE
      UBC(2,K)=U
      ENDIF
      IF(RE.GT.U) RE=U
      CIR=U-RE
      IF(CIR.LT.0.) CIR=0.
C
C     COMPUTE ACCUMULATIVE TOTAL FOR CIR THROUGH CURRENT MONTH
C
      TR=TR+P(K)
      TU=TU+U
      TRE=TRE+RE
      WCIRMO(K)=WCIRMO(K)+CDR*CIR
      TCIR=TCIR+CIR
      CIRFT=TCIR/12.
C
C     ASSIGN MONTHLY CIR DATA BY CROP, AND RESET COUNTER FOR DAYS AFTER PLANTING
C     AND CROP NUMBER FOR WINTER WHEAT AS NEEDED
C
      IF(ICALC.EQ.1) CIROBC(IM,K)=CIR
      IF(ICALC.EQ.2) CIRMBC(IM,K)=CIR
C
C     PRINT MONTHLY CIR FOR CROP
C
      IF(IOUT(1).LE.0) GO TO 410
      IF(ICALC.EQ.1) THEN
      IF((DOFF.GT.0.).AND.(DIFF.LE.0.)) WRITE(10,380) MON(K),NGD,TAGD,
     1  P(K),PDH,F,COFF(NC),U,RE,CIR
  380 FORMAT(4X,A3,4X,I3,1X,F4.1,1X,F5.2,2X,F4.1,1X,F5.2,6X,F4.2,1X,
     1  F5.2,1X,F5.2,1X,F5.2)
      IF((DOFF.LE.0.).AND.(DIFF.GT.0.)) WRITE(10,390) MON(K),NGD,TAGD,
     1  P(K),PDH,F,CIFF(NC),U,RE,CIR
  390 FORMAT(4X,A3,4X,I3,1X,F4.1,1X,F5.2,2X,F4.1,1X,F5.2,1X,F4.2,6X,
     1  F5.2,1X,F5.2,1X,F5.2)
      IF((DOFF.GT.0.).AND.(DIFF.GT.0.)) WRITE(10,400) MON(K),NGD,TAGD,
     1  P(K),PDH,F,CIFF(NC),COFF(NC),U,RE,CIR
  400 FORMAT(4X,A3,4X,I3,1X,F4.1,1X,F5.2,2X,F4.1,1X,F5.2,1X,F4.2,1X,
     1  F4.2,1X,F5.2,1X,F5.2,1X,F5.2)
      ENDIF
      IF(ICALC.EQ.2) WRITE(10,400) MON(K),NGD,TAGD,P(K),PDH,F,KC,KT,U,
     1  RE,CIR
      LCTR=LCTR+1
  405 IF((CT.EQ.'WG').AND.(K.EQ.8)) DAP=0.
      IF((ICALC.GE.2).AND.(CT.EQ.'WG').AND.(K.GE.9)) NC=NC-1
  410 CONTINUE
C
C     ASSIGN ANNUAL CIR DATA BY CROP
C
      IF(ICALC.EQ.1) TCIRO(IM)=TCIR
      IF(ICALC.EQ.2) TCIRM(IM)=TCIR
C
C     PRINT ANNUAL TOTALS FOR CROP
C
      IF(IOUT(1).LE.0) GO TO 450
      WRITE(10,420) NGDT,TR,TU,TRE,TCIR,CIRFT
  420 FORMAT(5X,'TOTAL',1X,I3,6X,F5.2,23X,F5.2,1X,F5.2,1X,F5.2,1X,'IN'/
     1  60X,F5.2,1X,'FT'/4X,64('='))
      LCTR=LCTR+3
      IF(MOD(IM+1,3).NE.0) GO TO 450
      L=LP-MOD(LCTR,LP)
      IF(L.LE.0) THEN
      LCTR=0
      GO TO 450
      ENDIF
      DO 440 I=1,L
      WRITE(10,430)
  430 FORMAT(' ')
  440 CONTINUE
      LCTR=0
C
C     COMPUTE CROP DISTRIBUTION RATIO AND WEIGHTED CIR FOR EACH CROP
C
  450 ACIR(IM)=TCIR
      WCIR(IM)=CDR*TCIR
      TAC2=TAC2+AC
      TCDR=TCDR+CDR
      TCIR2=TCIR2+TCIR
      TWCIR=TWCIR+WCIR(IM)
      WCIRFT=TWCIR/12
  460 CONTINUE
C
C     PRINT HEADINGS FOR ANNUAL WEIGHTED CIR TABLE FOR CROPPING PATTERN
C
      IF(IOUT(1).LE.0) GO TO 520
      IM=NCROPS(IAREA)+1
      WRITE(10,470) IM
  470 FORMAT(//4X,'TABLE ',I2,'. WEIGHTED ANNUAL CIR FOR CROPPING '
     1  'PATTERN'/4X, 66('=')/4X,'CROP',24X,'ACRES',6X,'CDR',6X,'CIR',
     2  5X,'WCIR'/4X,66('='))
      LCTR=LCTR+6
      DO 490 IM=1,NCROPS(IAREA)
      WRITE(10,480) CRTIT(ICROPS(IAREA,IM)),CACRE(IAREA,JYEAR,IM),
     1  CMIX(IAREA,JYEAR,IM),ACIR(IM),WCIR(IM)
  480 FORMAT(4X,A24,1X,F8.1,4X,F5.3,4X,F5.2,4X,F5.2)
      LCTR=LCTR+1
  490 CONTINUE
      WRITE(10,500) TAC2,TCDR,TWCIR,WCIRFT
  500 FORMAT(23X,'TOTAL',1X,F8.1,4X,F5.3,13X,F5.2,1X,'IN'/59X,F5.2,1X,
     1  'FT'/4X,66('=')/4X,'NOTE: THE WEIGHTED CONSUMPTIVE IRRIGATION ',
     2  'REQUIREMENT (WCIR)'/4X,'FOR EACH CROP IS COMPUTED BY ',
     3  'MULTIPLYING THE CONSUMPTIVE IRR-'/4X,'IGATION REQUIREMENT ',
     4  '(CIR) BY THE CROP DISTRIBUTION RATIO'/4X,'(CDR). IF WINTER ',
     5  'WHEAT IS IN THE CROP PATTERN, THE CDR IS'/4X,'BASED ON THE ',
     6  'ACRES OF THAT CROP HARVESTED IN THE SUMMER.')
      LCTR=LCTR+8
      IM=IM+1
      WRITE(10,505) IM,(MON(K),K=1,12),(WCIRMO(K),K=1,12),TWCIR
  505 FORMAT(//4X,'TABLE ',I2,'. WEIGHTED MONTHLY CIRS IN INCHES FOR '
     1  'CROPPING PATTERN'/4X,80('=')/5X,12(A3,3X),'TOTAL'/4X,
     2  12(F5.2,1X),1X,F5.2/4X,80('='))
      LCTR=LCTR+7
      L=LP-MOD(LCTR,LP)
      IF(L.LE.0) GO TO 520
      DO 510 I=1,L
      WRITE(10,430)
  510 CONTINUE
  520 RETURN
      END
      SUBROUTINE DATES(DAYJ,MONTH,MDAY,JYR,IFD)
C
C     THIS SUBROUTINE CONVERTS CALENDAR DATES TO JULIAN DAYS AND VICE-VERSA
C
C     DATA DECLARATIONS
C
      REAL DAYS(12)
      COMMON/BLKDAY/ DAYS
C
C     DETERMINE DAYS IN FEBRUARY
C
      DAYS(2)=28.
      IF(MOD(JYR,4).EQ.0) DAYS(2)=29.
      IF(IFD.GT.1) GO TO 30
C
C     CONVERT A CALENDAR DATE TO A JULIAN DAY
C
      DAYM=REAL(MDAY)
      IF(MONTH.GT.12) MONTH=12
      IF(MONTH.LT.1) MONTH=1
      IF(DAYM.GT.DAYS(MONTH)) DAYM=DAYS(MONTH)
      IF(DAYM.LE.0.) DAYM=1.
      DAYJ=0.
      DO 10 I=1,12
      IF(I.GE.MONTH) GO TO 20
      DAYJ=DAYJ+DAYS(I)
   10 CONTINUE
   20 DAYJ=DAYJ+DAYM
      RETURN
C
C     CONVERT A JULIAN DAY TO A CALENDAR DATE
C
   30 CUMDAY=0.
      DO 40 I=1,12
      CUMDAY=CUMDAY+DAYS(I)
      IF(DAYJ.LE.CUMDAY) GO TO 50
   40 CONTINUE
   50 MONTH=I
      DAYM=DAYJ-(CUMDAY-DAYS(I))
      MDAY=INT(DAYM)
C
C     END OF CONVERSION PROCEDURE
C
      RETURN
      END
